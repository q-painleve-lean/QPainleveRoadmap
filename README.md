# QPainleve Roadmap

Human-owned roadmaps for [QPainleve](https://github.com/q-painleve-lean/QPainleve). Each area is a
directory under `QPainleveRoadmap/` with a `README.md` (the definitive specification), suggested
Lean target signatures in `Suggested.lean`, and its arXiv topic in `metadata.toml`.

The conventions follow the [Tau Ceti roadmaps](https://github.com/TauCetiProject/TauCetiRoadmap);
areas here link to Tau Ceti roadmap areas they build on.
