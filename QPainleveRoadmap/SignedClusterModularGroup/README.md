# Roadmap: 反標準サイクルに付随する符号付きクラスター・モジュラー群

**Summary.** クラスター変異とラベルの置換から得られる有理写像について、どの変換が同じ群の元を表し、群全体をどの幾何的対称性で記述できるかを決定する。対象は、複素射影有理曲面上の向き付き反標準節点サイクルで、その全境界類が原始的、nef、平方零となる対のトーリック表示から得られる種である。独立な X 座標上の有理写像の等号で語を同一視し、交換行列と全座標を同時に反転する操作を加える。

主定理は、この群が、境界成分の類を回転または鏡映で置換する Picard 格子の等長変換に向きの符号を添えた群と反同型であることを述べる。向きを保つ部分群は指数 2 であり、この拡大は分裂する。境界成分が 1 個または 2 個の場合にも符号を保持し、Picard 作用が恒等である非自明な中心的対合を捉える。

語の関係式は、向きの符号、電荷核上の整数線形作用、一つの境界成分の行き先によって完全に決まる。境界と交わらない自己交点 −2 の曲線を持たない曲面では、格子側の群を Cremona 等長変換の群と比較する。この決定は固定した曲面の自己同型群の決定とは区別する。

ClusterAlgebras の変異の形式、IntegralLattices の整数格子、代数的トーリック幾何と有理曲面の交点理論に接続する。必要な定義と基本定理を、それぞれ自然な仮定の下で再利用できる形に整備し、有限階数の格子計算、点 blowup とトーリック表示、周期からの再構成、語と格子作用の対応、符号付き群の決定の順に進む。

## Conventions

幾何部分の基礎体は ℂ とする。曲面は ℂ 上の滑らかな連結射影スキームで、相対次元は 2 とする。有理性は ℙ² との双有理性という追加条件である。因子、線束、交点、blowup はこのスキーム上で定義し、有理性や境界に関する条件は、それを使う定理にだけ課す。Layer 0 の群環と X 有理写像は任意の体上で構成し、幾何への適用で ℂ を取る。Layer 1 の整数格子は曲面と独立に扱う。

Looijenga 対 (Y,D) は、滑らかな射影有理曲面と被約反標準有理節点サイクルの対である。D の成分数は n≥1 とし、向きは正規化上の成分と枝の巡回順を含む。n=1 では既約結節曲線の二枝の順序、n=2 では二成分の間の二節点を区別する。成分番号は ℤ/nℤ で読む。**対象対**とは、さらに δ=[D] が Pic(Y) の原始元、nef、δ²=0 を満たす Looijenga 対をいう。主定理の入力は対象対であり、一般の Looijenga 対やその節点 blowup にこの追加条件を課さない。

トーリック表示 P は、節点での有限回の blowup による (Ŷ,D̂)→(Y,D) と、滑らかな完備トーリック対への内部 blowup の有限列 (Ŷ,D̂)→(Ȳ,D̄)、およびトーラスの枠を記録する。内部中心にはラベルと同一境界成分上の順序を付ける。中心は境界の滑らかな部分に置き、相異なる中心を交換するときにその非衝突条件を課す。同じ点を繰り返し吹く場合は、その順序を保持する。この定義は対象対の追加条件から独立している。「最小対」は節点補助模型から戻る対象対を指し、(−1) 曲線を持たない最小有理曲面という意味ではない。

向き付き格子 N は階数 2、det はその整数値行列式である。内部中心の有限ラベル集合は I、A=ℤᴵ、電荷は v:A→N、v(eᵢ)=vᵢ とし、各 vᵢ は N の原始元である。H=im(v)、K=ker(v)、εᵢⱼ=det(vᵢ,vⱼ) と書く。L=Pic(Y)、M=Σℤ[Dⱼ] とする。M の原始性や rank H=2 は一般の表示の定義に含めない。M⊥ と K の同一視、対象対での rank H=2 はそれぞれ定理として構成する。

有限階数の自由整数加群 B に対し、指標トーラスのスキームを 𝕋(B)=Spec ℂ[B]、その複素点を T(B)=Hom(B,ℂ×)、関数体を ℂ(B)=Frac(ℂ[B]) と書く。開集合・有理写像・支配性は 𝕋(B) 上で述べ、中心 c の選択には T(B) を使う。T(A) 上の Xᵢ は独立変数である。中心 c∈T(A) と曲面のトーラス座標 z∈T(N) から得る Xᵢ=cᵢzᵛⁱ は曲面上の有理関数であり、独立変数を固定中心へ代入する操作とは区別する。指標の規約は ordᵤ(zʰ)=det(h,u)、中心の方程式は 1+cᵢzᵛⁱ=0 とする。

固定した c への代入は、一般には関数体 ℂ(A)→ℂ(N) の準同型を与えない。非零の Casimir 多項式が代入後に零となり得るためである。X 写像との評価の等式は共通の有理定義域で、または中心を変数に残した ℂ(A⊕N) 内で述べる。

語は、交換行列を始域・終域とする変異、ラベル置換、反転の有限列である。[a]₊ = max(a,0) とする。

    μₖ: ε′ᵢⱼ = −εᵢⱼ                         (k ∈ {i,j}),
        ε′ᵢⱼ = εᵢⱼ + [εᵢₖ]₊εₖⱼ + εᵢₖ[−εₖⱼ]₊  (それ以外),
        X′ₖ = Xₖ⁻¹,
        X′ᵢ = Xᵢ Xₖ^[εᵢₖ]₊ (1+Xₖ)^(−εᵢₖ)    (i ≠ k).
    σ:  ε′ᵢⱼ = ε_{σ(i),σ(j)},  X′ᵢ = X_{σ(i)}.
    ς:  ε′ = −ε,  X′ᵢ = Xᵢ⁻¹.

始域と終域の行列が同じ語をループとする。Γ̃ はその X 有理写像の群で、積は点の写像の合成である。Γ は反転を含まないループの像である。語の偶奇は、まず語に対して定義し、Γ̃ 上への降下は定理として証明する。A 座標にも恒等に作用することを同一視の条件に加えない。

語 w の後に w′ を実行すると、点写像は `F_{w′}` ∘ F_w、関数体の引き戻しは F_w* ∘ `F_{w′}*` になる。関数体の代数自己同型を Lean の実体にする場合、Γ̃ はその像の反対群を取る。Picard 作用の主定理は、点写像の規約では Γ̃ᵒᵖ ≅ Ĝ と述べる。

    G⁺ = {g ∈ O(L) | ∃k ∈ ℤ/nℤ, ∀j, g[Dⱼ] = [D_{j+k}]}.
    Ĝ  = {(g,η) ∈ O(L)×{±1} |
           ∃k ∈ ℤ/nℤ, ∀j, g[Dⱼ] = [D_{ηj+k}]}.

Ĝ の積は成分ごとの積である。格子の等長変換 g と境界の順像を区別し、g は曲面同型の引き戻しを表す。境界と交わらない自己交点 −2 の既約曲線を内部 (−2) 曲線と呼ぶ。

## Layer 0: 語と独立変数上の有理写像

### 0.1 指標トーラスと関数体

体 k と有限自由整数加群 B に対し、群環 k[B]、スキーム 𝕋_k(B)=Spec k[B]、k 点 Hom(B,k×)、分数体 k(B) を構成する。k[B] の指数 b に対応する単項式を Xᵇ とする。基底を選んだ Laurent 多項式環との同型、単項式の線形独立性、群環が整域であることを証明する。

格子準同型 f:B→C の指標写像 𝕋_k(C)→𝕋_k(B) を構成し、単項式の引き戻し Xᵇ↦Xᶠ⁽ᵇ⁾、恒等・合成・基底変更との整合性を証明する。格子の単射に対して群環と関数体の単射を、同型に対してトーラスと関数体の同型を得る。k(B) の自己同型は基底単項式への作用で決まり、トーラスの支配的有理写像の等号は関数体の引き戻しの等号と同値である。特殊点での値の一致をこの等号の定義にしない。

*Needs:* Mathlib の有限自由加群、`AddMonoidAlgebra`、`FractionRing`、`AlgEquiv`、アフィンスキームと構造射。

### 0.2 型付きの語とその解釈

有限ラベル集合上の歪対称整数行列を対象、Conventions の三種の操作を生成辺とする有限路を構成する。始域・終域を保持した連結、逆路、ラベル変更を定義する。各変異が歪対称性を保ち、指定公式が関数体同型を与えることを証明する。分母 Xₖ と 1+Xₖ は独立変数の関数体では非零である。変異公式の出典は [FG] §1.2.2 (7)、§1.2.4 (13) である。

*Needs:* 0.1。整数の正部分の恒等式。

### 0.3 有理写像の群と反転の交換

二度の同じ変異と二度の反転が恒等になること、ςμₖ と μₖς、ςσ と σς がそれぞれ同じ始域・終域と同じ有理写像を持つことを証明する。ここで μₖς の μₖ は始域 ε における変異、ςμₖ の μₖ は −ε における変異であり、行列を固定して交換すると読まない。

基点 ε でのループの関数体同型の像を部分群として構成し、その反対群を Γ̃ とする。反転のないループの像から Γ を構成する。これは X 有理写像の等号による語の商と同型である。偶数回の反転を含む語を反転なしへ、奇数回の語を最初の一回の反転と反転なしの語へ移す。対象対の表示から得られる種について、偶奇が有理写像だけで決まることを 7.2 で証明する。一般の交換行列にこの結論は仮定しない。[BGM] §3.1 冒頭は反転を加える定義の参照先である。

*Needs:* 0.2。部分群、群の反対群、同型の像。

### 0.4 電荷核上の単項式の輸送

階数 2 の N の原始電荷列に対して K=ker(v) を取る。変異で v′ₖ = −vₖ、v′ᵢ = vᵢ+[εᵢₖ]₊vₖ と置く。以下の整同型の合成を終域の核に制限し、w:K_end → K_start を構成する。

    Bₖ(e′ₖ) = −eₖ,  Bₖ(e′ᵢ) = eᵢ+[εᵢₖ]₊eₖ  (i ≠ k).
    Bσ(e′ᵢ) = e_{σ(i)},  Bς(e′ᵢ) = −eᵢ.

反転では電荷列自体を保ち det を反転するため、Bς は電荷写像を可換にする写像ではなく、単項式の引き戻しを表す。全生成操作について、核上の二項式の指数が零となり Xˣ ∘ F_w = `X^{w(x)}` であることを証明する。連結について `w_{ww′}` = w_w `w_{w′}` とする。さらに電荷列が N を有理的に張る場合に K=ker(v)=ker(ε) を証明する。核の輸送自体はこの追加条件を使わない。これは [FG] の基底変異からの計算であり、詳細は [補足 B](#b-電荷と有限指数) に記す。

*Needs:* 0.1–0.3。整数行列の核、有限自由加群の線形同型。

### 0.5 境界付値を記録する整数列

初期整数列 b を、変異で次のように更新する写像を定義する。置換では `b′ᵢ=b_{σ(i)}`、反転では b′ᵢ=−bᵢ とする。

    b′ₖ = −bₖ,
    b′ᵢ = bᵢ+[εᵢₖ]₊bₖ−εᵢₖ min(0,bₖ)  (i ≠ k).

更新の合成と逆操作の整合性を証明する。これが実際の境界因子の付値を輸送することは 5.5 の目標であり、任意の付値で ord(1+f)=min(0,ord(f)) を仮定しない。[GHK-C] (1.4) の境界付値による熱帯化との対応を証明する。

*Needs:* 0.2。整数の順序・最小値。

### Examples

**Checks.** ε₁₂=1 の二変数の種で μ₁ は (X₁⁻¹,X₂(1+X₁)) となる。ς の後の変異は (X₁,X₂⁻¹(1+X₁)⁻¹) で、先に変異して全成分を逆数にしたものと一致する。b=(1,−2) は μ₁ で (−1,−2) に移り、変異後の行列で再度 μ₁ を行うと (1,−2) に戻る。bₖ=0 のとき一般の関数 f=−1+t では ord(1+f)>0 となるため、付値公式には 5.5 の幾何的根拠が必要である。

### Dependencies

0.1 → 0.2 → 0.3、0.1–0.3 → 0.4、0.2 → 0.5。曲面の存在はこのレイヤーの仮定にしない。

## Layer 1: 境界格子と向きの反転

### 1.1 サイクル交点行列と飽和

有限自由整数加群 L に非退化な単模対称形式を置く。n≥1、δ=ΣDⱼ を原始的特性元とし、次を仮定する。

    Dᵢ·Dⱼ = −2[i=j]+[j=i+1]+[j=i−1],
    x² ≡ x·δ  (mod 2)  (x ∈ L).

角括弧は各等式の指示値である。Dⱼ の一次独立性、δ²=0、M∩M⊥=ℤδ、M_Q+(M⊥)_Q=δ⊥_Q を証明する。Mˢ=(M⊗ℚ)∩L に対し、Mˢ/M が位数 t の巡回群で t|n となることを、サイクルの差分方程式から導く。

さらに L の符号数が (1,9) なら、δ⊥/ℤδ は階数 8 の負定値偶単模格子、M/ℤδ は `A_{n−1}(−1)` であり、t²|n、n≤9 を証明する。偶単模格子の全分類は使用しない。[補足 A](#a-境界格子の整数計算) の整数計算を証明目標とする。

*Needs:* 有限自由加群の双対、原始部分加群、飽和、直交補、Smith 標準形、Gram 行列式。

### 1.2 鏡映を持ち上げる対合

1.1 の符号数を仮定しない部分の条件の下で、ある j₀ と f∈L が存在して f²=−1、f·Dⱼ=[j=j₀] となることを証明する。U=ℤδ⊕ℤf の Gram 行列は [[0,1],[1,−1]] であり、L=U⊕U⊥ となる。

j₀ 以外の境界類の反射が生成する A 型の対称群の最長元 w₀ を構成し、`g₀=id_U⊕(−w₀|_{U⊥})` と置く。g₀ は対合的等長変換で、f、δ を固定し、Dⱼ を `D_{2j₀−j}` に移し、κ∈M⊥ に対し g₀κ=−κ+2(κ·f)δ を満たす。f は格子の元として構成し、楕円曲面の切断や実際の例外曲線を仮定しない。

この主要な格子定理を `exists_cycle_reversing_involution` として [Suggested.lean](Suggested.lean) に述べる。証明は [補足 A](#a-境界格子の整数計算) の飽和と座標反転による。

*Needs:* 1.1。整数値双対の延長、単模直交分解、隣接互換による対称群。

### 1.3 符号を保持した境界等長群

Conventions の G⁺、Ĝ を部分群として構成する。符号射影の核が G⁺、(g₀,−1) が位数 2 の切断を与えることを証明し、共役作用 h↦g₀hg₀ による半直積 Ĝ≅G⁺⋊C₂ を得る。

n≥3 で Ĝ→O(L) が単射となること、n≤2 では Ĝ=G⁺×{±1} となることを証明する。後者の中心的元 (id,−1) と、1.2 で構成した (g₀,−1) を定義で同じものにしない。

*Needs:* 1.1–1.2。部分群、半直積、巡回添字の置換。

### 1.4 電荷核と境界像による忠実性

L の等長変換で M⊥ と各 Dⱼ を点ごとに固定するものは恒等であることを証明する。証明は M_Q+(M⊥)_Q=δ⊥_Q と、δ に交点 1 を持つ元の平方の保存を使う。従って g∈G⁺ は `(g|_{M⊥},gD₀)` で、(g,η)∈Ĝ は `(η,ηg|_{M⊥},j)` で決まる。ここで j は引き戻しに対応する境界の順像 D₀↦Dⱼ、すなわち `gD_l=D_{η(l−j)}` を満たす添字とする。

*Needs:* 1.1、1.3。ℚ 上の非退化双線形形式。

### Examples

**Checks.** n=1 では Gram 行列は (0)、n=2 では [[−2,2],[2,−2]] である。n=2 では鏡映と恒等の境界置換が同じでも符号付き元は異なる。n=3 では j↦−j は 1 と 2 を交換し、回転ではない。U の行列式は −1 であり、平方が −1 の f を平方 0 の元に置き換えた分解を使用しない。

### Dependencies

1.1 → 1.2 → 1.3、1.1 と 1.3 → 1.4。1.2 の一般格子定理は符号数や曲面を仮定しない。n≤9 と t²|n にだけ符号数 (1,9) を使う。

## Layer 2: 曲面の基礎と有理曲面への適用

### 2.0 曲線・曲面のコホモロジーと Euler 標数

ℂ 上の次元 ≤2 の射影スキーム X と coherent sheaf F に対し、各 Hⁱ(X,F) の有限次元性、i>dim(supp F) での消滅を証明する。非被約曲線・有限厚化も含める。豊富線束 A について、十分大きな m で F⊗Aᵐ が大域生成され、全ての i>0 のコホモロジーが消滅することを証明する。既存の有限射の coherent pushforward と閉埋込のコホモロジー比較を再利用し、一般の有限射のコホモロジー比較と射影公式を、正規化と曲線次数に使える形で供給する。有限射の比較は有限アフィン被覆上の Čech 複体の各項の比較から得る。

既存の層コホモロジーと長完全列を用い、χ を `AlgebraicGeometry.Scheme.Modules.eulerCharBelow` に接続する。切断次数は曲面で 3、曲線で 2 とし、有限次元性と次の次数の消滅を供給して既存の加法性を適用する。χ の同型不変性、短完全列での加法性、有限台の層の χ が長さの和となることを公開する。

証明入力は、アフィン上の quasi-coherent cohomology の消滅、有限アフィン被覆による Čech 比較、射影空間の O(d) の計算、coherent kernel、十分大きな twist の section の延長である。有限直和 O(−p)ʳ→F の全射と次元シフトを構成し、[Debarre-S] Theorem 2.28、Corollary 2.29、Theorem 2.37、Corollary 2.38 の証明へ接続する。射影埋込に使う ℙᴺ の N は任意とし、ℙ¹・ℙ² では既存の H⁰・中間消滅・ℙ¹ の計算を再利用し、残る ℙ² の上次数を計算する。coherent kernel の有限性は Noetherian affine 上の既存結果を開制限と局所性で貼り合わせる。支持次元の消滅には、ann(F) が定める閉部分スキームへ F を移し、次元 d の射影スキームが d+1 本の超平面の補集合で覆えることを使う。これは高々三つのアフィン開による被覆であり、Čech 複体の次数上界が必要な消滅を与える。これらの入力の必要部分も本項の実装目標とする。

*Needs:* Mathlib と Tau Ceti のスキーム、層加群、coherent sheaf、層コホモロジー、短完全列と長完全列、射影空間・twisting sheaf の既存の型。有限性と消滅は既存の `finrank` の定義から仮定せず、ここで供給する。

### 2.1 曲面、因子、線束、交点

滑らかな射影複素曲面を扱う。本項に有理性は不要である。Pic(Y) は既存 `TauCeti.AlgebraicGeometry.LineBundleClass` の加法表記とし、既存の Cartier 因子からの準同型と Cartier 類群との同型を利用する。有効因子と非零 section、有効線束類の対応、曲線への制限、標準束 ω_Y=∧²Ω¹_Y、引き戻しの函手性を整備する。既約曲線が Cartier 因子になるために必要な、二次元正則局所環の高さ 1 の素イデアルの主性も証明対象とする。

曲面上の整数値交点 B:Pic(Y)×Pic(Y)→ℤ を構成し、任意の閉じた整曲線 i:C→Y について B(x,[C]) が既存 `LineBundleClass.intersectionNumber` による制限次数と一致することを証明する。C を滑らかと仮定しない。有限正規化 ν:C̃→C に対し、O_C→ν_*O_C̃ の余核 Q は有限台を持ち、Q と Q⊗L の長さが等しいことから、

    deg_C(L)=χ(C,L)−χ(C,O_C)=deg_C̃(ν*L)

を導く。これにより正則曲線上の既存の次数加法性を全ての整曲線へ移す。Cartier 因子の素因子和で交点を定め、主因子で値が零となることを示し、既存 Cartier–Picard 同型で線束類上へ降ろす。

双線形性、対称性、射影公式、局所交点長 length(O_Y,p/(f,g)) との一致、相異なる既約曲線の交点の非負性を証明する。nef は全既約曲線との交点の非負性、豊富は線束の豊富性として定義する。有効因子 D の台の各成分 C で D·C≥0 なら D が nef となる補題も得る。Pic(Y) の有限自由性・単模性はここでは仮定せず、有理曲面への適用で証明する。次数と交点の構成は [Debarre-S] §3.2, Definition 3.5、Theorem 3.6、Lemma 3.7 を参照する。

*Needs:* 2.0。既存の `AlgebraicGeometry.Scheme`、局所環、Cartier 因子、線束、`LineBundleClass.pullback`、曲線の Euler 次数。有限正規化と有限台の長さの必要な曲線版を含む。

### 2.2 点 blowup と共通解消

滑らかな射影複素曲面の閉点 p の ideal sheaf による blowup を構成する。有理性や境界は仮定しない。正則パラメータ u,v に対する二つの chart R[t]/(v−ut)、R[s]/(u−sv) で例外曲線と固有変換を記述する。例外曲線 E≅ℙ¹、O_E(E)≅O(−1)、blowup の滑らかさ・射影性、および

    Pic(Bl_p Y)=π*Pic(Y)⊕ℤE,  E²=−1,
    (π*x)·E=0,  K_{Bl_p Y}=π*K_Y+E

を証明する。有限列では全変換の例外類を用いて直交基底を維持する。境界の滑らかな点の blowup では被約反標準境界は D′=π*D−E で E を含まない。節点の blowup では D′=π*D−E が固有変換と E の和となる。自己節点でも二枝を数える。

線束 L の引き戻しは Hⁱ(Y,L)≅Hⁱ(Bl_p Y,π*L) を与えることを、二 chart の局所 Čech 計算と大域比較から証明する。全整数 m について例外曲線の完全列を構成し、

    0→π*L((m−1)E)→π*L(mE)→L_p⊗O_{ℙ¹}(−m)→0,
    χ(π*L(mE))=χ(L)+m(1−m)/2

を得る。正整数 m に限った帰納にせず、ℙ¹ の χ(O(d))=d+1 から両方向の漸化式として証明する。

曲面の指定された双有理写像の基点を有限回の点 blowup で解消し、二つの射を支配する共通解消を構成する。相異なる点の blowup の交換、有限個の節点 blowup 列の共通細分、指定した例外曲線の縮約後の射の降下を証明する。[Stacks] Tags 0C5R、0C5S の滑らかな射影曲面の特殊形を対象とする。基点を持つ線形系の解消では、固定成分を除いた後の交点数の減少を停止の根拠とする。正則双有理射の分解は [Stacks] Tag 0C5R の例外線の conormal O(1) と正規な標的への proper quasi-finite 射による証明を用い、後の符号数や一般の (−1) 曲線縮約を先に仮定しない。

*Needs:* 2.1。`AlgebraicGeometry.Scheme.IdealSheafData.blowup` とその普遍性、滑らかな二次元局所環のパラメータ。

### 2.3 有理曲面の数値的定理

滑らかな射影有理曲面について h¹(O_Y)=h²(O_Y)=0、χ(O_Y)=1、Pic(Y) が有限自由、交点形式が単模、rank Pic(Y)+K_Y²=10 であることを証明する。有理性は ℙ² との双有理性で扱い、既存 `Scheme.IsRationalOver` との比較には曲面の次元からアフィン空間の添字数が 2 となる補題を置く。ℙ² の計算、2.2 の Picard 直交分解とコホモロジー比較、共通解消を使い、最小有理曲面の分類を先に仮定しない。

任意の線束類 x と既約曲線 C に対し、

    χ(O_Y(x))=1+(x²−x·K_Y)/2,
    h²(O_Y(x))=h⁰(O_Y(K_Y−x)),
    2p_a(C)−2=C²+C·K_Y

を証明する。Riemann–Roch は ℙ² の O(d) の計算と 2.2 の全整数 m の Euler 漸化式により点 blowup の両方向へ移し、共通解消で有理曲面へ移す。これから x²≡x·K_Y mod 2 も得る。[Hacking-S] Theorems 5.2–5.3、[Stacks] Tag 0FVV(6),(7) が主張の参照先である。

上次数の双対性には、χ の式とは別に完全 pairing H²(L)×H⁰(ω_Y⊗L⁻¹)→ℂ を構成する。ℙ² の Čech 単項式の係数から trace を作り、点 blowup の標準束公式で trace を移す。例外曲線の twist 完全列の connecting map と双対 twist の restriction map が、ℙ¹ の residue pairing の下で互いに随伴であることを二 chart で証明する。m≤1 では H¹(O_E(−m))=0、m≥2 では H² 側の cokernel と H⁰ 側の kernel の双対性を使い、全 m へ完全性を移す。m=0 の比較で逆向きへも移せるため、共通解消に沿って対象曲面へ降ろせる。この pairing の可換性を独立した補題として公開し、数値的 Euler 漸化式だけで代用しない。

算術随伴は O(−C)→O→O_C の完全列から導く。正規化の種数と有限台の余核の長さから p_a(C)≥0 を示す。p_a(C)=0 なら C は滑らかで、滑らかな点 p に対する O_C→O_C(p) の完全列から二つの section を得て、有限次数 1 の C→ℙ¹ を構成する。従って C≅ℙ¹ である。高次元の Riemann–Roch や全 coherent sheaf の双対性は本項の目標に含めない。

*Needs:* 2.0–2.2。ℙ¹・ℙ² の Čech 計算、cup product と trace、線束の双対と制限。

### 2.4 正錐、豊富性、曲線の縮約

滑らかな射影有理曲面について、ℙ² との共通解消と 2.2 の直交分解から、実 Picard 空間の交点形式の符号数が (1,ρ−1) であることを証明する。豊富類が選ぶ正錐成分、その閉包、非零の nef 等方類との交点による成分の識別を構成する。正錐の同じ閉包に属する類の交点の非負性も証明する。

滑らかな射影有理曲面上の整数類 h が h²>0 かつ全既約曲線 C で h·C>0 を満たすことと、h が豊富であることの同値を証明する。[Debarre-S] §4.1, Theorem 4.1 の曲面における証明を、有効性、H¹ の次元の安定化、大きな冪の大域生成、有限射による豊富性の引き戻しに分ける。この証明に現れる有効因子は特異・非被約の場合を含むため、その各既約成分上の次数が正なら制限線束が豊富である一次元の定理も証明する。正規化と conductor の有限台、nilpotent ideal の有限 filtration、2.0 の消滅と大域生成を用いて被約成分から厚化へ移す。豊富類と nef 類の和の豊富性、豊富錐の開性、負の既約曲線の有効曲線錐の閉包での極線性を独立した補題として得る。

任意の滑らかな射影複素曲面について、滑らかな有理 (−1) 曲線を滑らかな点へ縮約できること、互いに素な有限集合の同時縮約、十分大きな N で Nπ*h−E が豊富となることを証明する。[Stacks] Tag 0C2N, Lemma 54.16.9(1)、Tag 0C2I の縮約の一意性を用いる。縮約の証明では、線形系による射の構成だけでなく、縮約点の完成局所環が ℂ[[u,v]] であることと滑らかさを証明する。必要な形式関数の比較はこの例外曲線とその有限厚化に限定する。

*Needs:* 2.1–2.3。実数上の二次形式、曲線の次数、射影性。

### 2.5 階数 2 の扇とトーリック模型

階数 2 格子の有限で滑らかな完備扇の曲面、トーラス開部分、境界成分、指標の因子を構成する。曲面の射影性も証明する。隣接する原始射線が整数基底であることと滑らかさの対応、扇の細分と節点 blowup の対応、共通の滑らかな細分、トーリック Picard 群の表示を証明する。

滑らかな射影有理曲面と反標準節点サイクルの対には、有限回の節点 blowup の後でトーリック模型が存在することを証明する。[GHK-Mirror] v3 Proposition 1.3 の最小有理曲面と ruling による証明を、点 blowup・縮約の言葉で構成する。入力として、(−1) 曲線のない射影有理曲面が ℙ² または Hirzebruch 曲面 F_a（a=0 または a≥2）になることを証明する。[Vakil-S] Class 16 と Class 17 §§1–2 の証明で必要な、平方非負の有理曲線の存在、その線形系から得る ruling、ℙ¹ 上の階数 2 ベクトル束の分裂もこの対象に含める。平方非負の有理曲線 C を C²、次に C·H が最小となるように選び、|C| の各元の既約性・滑らかさ、h⁰(O(C))=C²+2≤3、大域生成を証明する。C²=1 では有限次数 1 の ℙ² への射、C²=0 では全ファイバーが ℙ¹ である ℙ¹ への射を得る。

後者を射影束と同定する橋も構成する。ファイバー類 F は F²=0、K·F=−2 と特性合同式から原始的である。実際 F=2G は G²=0、K·G=−1 に反する。単模性により L·F=1 なる線束 L を取り、L((r−1)F)→L(rF)→O_F(1) の完全列と H¹ の次元安定化から各ファイバー近傍で二つの section を持ち上げる。この局所自明化と L の pushforward から階数 2 ベクトル束の射影化を得る。ℙ¹ 上の階数 2 ベクトル束 V の分裂は、H⁰(V(−a))≠0 となる最大の a を取り、section の飽和から O(a) を部分線束として O(b) を商に持つ完全列を作って証明する。最大性と H¹(O(−1))=0 から b≤a を得て、H¹(O(a−b))=0 により列が分裂する。最大の a の存在には V と V∨ の十分大きな twist の大域生成を用いる。

最小有理曲面の分類の入力 h¹(O_Y)=h⁰(O_Y(2K_Y))=0 は、2.2 の比較と pluricanonical section の点 blowup 不変性から得る。[Vakil-S] Class 16 の Pic(Y)=ℤK_Y の場合の排除には、2.3 の単模性と rank Pic(Y)+K_Y²=10 を使う。曲面分類の証明に一般の Noether 公式や位相的 Poincaré 双対性は追加しない。散乱図や鏡の構成は依存しない。

*Needs:* 0.1、2.1–2.4。Tau Ceti の `TauCeti.Toric.Fan` と `TauCeti.Toric.Fan.algebraicRealization`、半群環の局所化、ℙ² と Hirzebruch 曲面。

### 2.6 平方零の対から境界格子へ

対象対について rank L=10、符号数 (1,9)、x²≡x·δ mod 2 と、1.1 のサイクル交点行列を証明する。nef 性と δ²=0 より δ·Dⱼ=0 を得て、随伴公式と節点の数から各自己交点を求める。δ の原始性から境界類の一次独立性を得る。

節点 blowup 後の被約境界は一般に nef でも平方零でもない。最小対の δ の全変換と被約境界を区別する。全変換の係数は元の成分で 1、新しい節点例外成分で二枝の係数の和である。同じ共通模型からこの全変換を持つ二つの最小化の例外集合が一致し、最小対が一意に同型となることを証明する。

*Needs:* 1.1、2.1–2.5。縮約の降下と正規性。

### Examples

**Checks.** ℙ² で H²=1、χ(O(dH))=(d+1)(d+2)/2。blowup 一回で E²=−1、K² と Picard 階数はそれぞれ 1 減り、1 増える。二枝の重みが 1,1 の節点 blowup の新重みは 2 であり、被約境界の新例外成分との交点は 1 になる。この模型を再び平方零 nef の最小対として扱わない。2.1–2.2 は境界を指定しない Bl_p ℙ² にも適用でき、特異曲線の次数は正規化の Euler 差の相殺で計算する。

## Layer 3: 電荷、中心、周期

### 3.1 中心を動かす標識付き表示

固定した滑らかな完備扇 Σ、境界に載る内部中心のラベル、同一成分上の順序から、各 c∈T(A) に実際の blowup 曲面 Ỹ_P(c) を構成する。中心は 1+cᵢzᵛⁱ=0 で与え、同じ点の反復は、その境界の固有変換上の次の点を吹くものとする。標準の格子と標識の向きを、

    L̃_P=Pic(Ȳ_Σ)⊕⊕ᵢℤEᵢ,
    μ̃_{P,c}:L̃_P ≅ Pic(Ỹ_P(c))

と固定する。μ̃ はトーリック因子の引き戻しと全変換例外類によって決まり、任意の中心依存の標識を選ばない。指定された有限節点縮約は追加データとし、その全例外類の直交補 L_P、包含 j_P:L_P↪L̃_P、引き戻しを用いて Y_P(c)、`μ_{P,c}:L_P≅Pic(Y_P(c))` を得る。固定境界類 dⱼ は実際の [Dⱼ] へ移る。これらは一般の Looijenga 対の表示に対する定義である。

相異なる中心の開集合、指定した有限列の写像が定義される開集合を構成し、その非空性を非自明な Laurent 単項式の非等式から示す。必要な代数性は中心パラメータの写像に課し、曲面と縮約は各 c について構成する。任意基底上の相対縮約やモジュライスタックは要求しない。標識、境界の対応、点ごとの同型が開集合の縮小と表示変更に整合することを証明する。

ある中心で対象対を与える場合は、全中心で境界交点行列と原始性が標識により保存される。境界の台の各成分との交点が非負なら有効境界は nef であるという 2.1 の補題を使い、対象対の条件が保存されることを系として示す。[GHK-M] §2 の toric model と中心の構成を参照する。

*Needs:* 0.1、2.1–2.2、2.4–2.5。対象対に対する最小化の比較には 2.6。

### 3.2 電荷核と境界直交格子の同定

一般の順序付きトーリック表示に対し、κ∈M⊥ を補助模型へ引き戻して κ↦(κ·Eᵢ)ᵢ が K への整数加群同型を与えることを証明する。その逆を ι_P:K_P≅M_P⊥⊂L_P と書き、K の形式はこの同型で移す。逆写像は電荷関係 x からトーリック因子類 H_x を構成し、H_x−ΣxᵢEᵢ として得る。節点 blowup の例外直和因子を除くことで一般の基の対へ降りる。標識について `μ_{P,c}∘ι_P` が実際の Picard 群への同じ構成に一致することを証明する。補助模型への写像は ι̃_P=j_P∘ι_P:K_P→L̃_P と定め、節点縮約が空なら j_P=id とする。

さらに、rank H=2 を仮定せず、

    L_P/M_P ≅ coker(v*:N*→A*),
    rank K=#I−rank H

を得る。rank H=2 の場合に、Smith 標準形から [Mˢ:M]=[N:H]=s を得る。[GHK-C] Theorem 5.5 と証明の式 (5.1) を参照し、有限指数の電荷像を含むトーリック交点計算を本項で証明する。同論文の unimodular な seed datum の仮定を有限指数の場合へそのまま適用しない。

**対象対への適用。** Picard 階数と扇の射線数から m=12−n、rank K=10−n、rank H=2 を証明する。1.1 と上の商の同型から s²|n、n≤9、s∈{1,2,3} を得る。境界に沿う巡回順で交点を計算し、ε の全成分を割る整数 d に対し、

    κ²≡−Σxᵢ² (mod d),  κ=ι_P(x)

を証明する。この合同式自体は一般の表示にも成立する。交差項の符号を任意のラベル順に流用せず、合同式を順序に依存しない結論として取り出す。[補足 B](#b-電荷と有限指数) に導出を記す。

*Needs:* 0.1、2.1–2.2、2.5、3.1。対象対の数値的帰結には 1.1、2.6。トーリック因子の完全列、整数行列の余核と Smith 標準形。

### 3.3 中心の整列と有限被覆

有限自由整数加群間の v:A→N に対し、H=im(v)、K=ker(v)、J=Hom(N/H,ℂ×) と置く。中心 c での写像 z↦(cᵢzᵛⁱ) は T(A)→T(K) の c|_K 上のファイバーへ全射で、その平行移動の核が J であることを証明する。c₁|_K=c₂|_K なら比 c₂/c₁ は H の指標となり、Smith 標準形と ℂ× の可除性により N へ延長できる。延長の選択差は J である。この結果に rank H=2 は不要であり、Smith 標準形により J は `(ℂ×)^(rank N−rank H)` と有限巡回群の積として記述される。トーリック表示に適用すると、その平行移動は順序付き中心を整列し、向きと Picard 標識を保つ。

**有限指数の場合。** rank H=rank N のとき |J|=[N:H]=s であり、ℂ(H)⊂ℂ(N) は有限拡大となる。H の全単項式を固定する ℂ 自己同型がちょうど J の平行移動であることを証明する。sN⊂H と、関数体の元 r が rˢ=1 を満たせば ℂ の定数となることを用いる。この命題は任意の有限指数 s に対して述べる。

評価写像 ev_P:𝕋(A)×𝕋(N)→𝕋(A)、ev_P(c,z)=(cᵢzᵛⁱ)ᵢ を構成する。z=1 で c を回収するので支配的であり、中心の任意の非空開集合に制限しても支配的である。従って中心を変数に残した評価後の有理写像の等号から、独立 X 変数上の等号を回収できる。

*Needs:* 0.1、3.1–3.2。Smith 標準形、ℂ における根の存在、整スキームの稠密開集合と関数体。

### 3.4 境界の周期と中心公式

向き付き節点サイクル D の正規化で、多重次数零の線束を節点の接着定数で表し、Pic⁰(D)≅ℂ× を構成する。接着定数の積は局所自明化の変更に不変で、向きを逆転すると逆数になる。n=1 の二枝と n=2 の二節点にも同じ定義を使う。[GHK-M] Lemmas 2.1、2.5 を参照する。

Pic⁰(D)≅ℂ× の上の同型を λ_D と書く。一般のトーリック表示の周期を、標識と 3.2 の逆同型の向きを固定して

    a_{P,c}(x)=λ_D(restriction(μ_{P,c}(ι_P(x))))  (x∈K_P)

と定義する。線束の tensor と制限により指標であり、節点 blowup の引き戻しに不変であることを証明する。向きの符号 η を持つ対の同型 Ψ:Y₀→Y₁ に対して、実際の境界直交類での自然性は a₁(x)=a₀(Ψ*x)^η となる。

同じ表示の二中心 c,d に対し、接着定数の比を計算して

    a_{P,c}(x)/a_{P,d}(x)=((c/d)^x)^θ

を証明する。θ∈{±1} は接着比と指標の規約から一度定まる。固定した基準中心 d によって `χ_P(x)=a_{P,d}(x)/(d^x)^θ` と置くと、比の公式から基準中心に依存しない指標となり、`a_{P,c}=χ_P·(c|_K)^θ` を得る。χ_P=1 は仮定しない。K は A の直和因子なので中心から周期への写像は全射である。[GHK-M] Proposition 2.9、Corollary 2.10、[GHK-C] Theorem 5.5 の必要な式に対応する。

内部 (−2) 曲線 C があれば [C]∈K、[C]²=−2、a_c([C])=1 であることを証明する。逆向きの主張や、平方 −2 の全類と変形で実現する根との同一視は仮定しない。

*Needs:* 2.1–2.2、3.1–3.3。線束の制限、正規化上の接着、K が A の直和因子であること。

### 3.5 根を避ける周期の存在

任意の有限自由整数加群が ℂ× への単射指標を持つことを、基底と相異なる素数から証明する。原始元 δ が指定された場合は δ を整数基底 δ,β₁,…,β_r に延ばす。相異なる奇素数 pᵢ によって a(δ)=1/2、a(βᵢ)=pᵢ と定めると、a:K→ℂ× は単射であることを証明する。この一般定理の結論は、全ての非零元 x で a(x)≠1 となることである。

対象対への適用では δ は K の形式の根基に属するため、平方 −2 の α とその全ての δ 平行移動も平方 −2 であり非零である。従ってこの a はそれらの全てで値 1 を避ける。3.4 の全射性で a を中心の周期として実現する。δ を固定する格子等長変換 g に対して a∘g、およびその逆数も根を避ける。全射性の証明にはこの一点の存在で足りる。全ての根を避ける集合が一つの Zariski 開集合であるとは主張しない。

*Needs:* 3.2–3.4。原始元の基底への延長、素因数分解の一意性。

### Examples

**Checks.** 内部中心が零のトーリック対では A=K=0、H=0、J=T(N) となるため、一般の J を有限群と定義できない。H=⟨(1,1),(−1,1)⟩⊂ℤ² では s=2、J の非自明元は (z₁,z₂)↦(−z₁,−z₂) である。z₁z₂ と z₁⁻¹z₂ は固定されるが z₁ は固定されない。a(2δ−β₁)=1/(4p₁)≠1 であり、χ_P≠1 の場合の中心は a/χ_P を用いて求める。

### Dependencies

3.1 → 3.2 → 3.3 → 3.4 → 3.5。基礎は Layers 0–2。有限被覆の誤差 J と中心周期の定数 χ_P を保存する。

## Layer 4: 周期による再構成と格子作用の実現

### 4.1 負曲線、錐、有効類の保存

一般の Looijenga 対について、境界以外の負の既約曲線は、D と交点 1 の (−1) 曲線または内部 (−2) 曲線であることを算術随伴から証明する。豊富類 h を固定し、e²=e·K_Y=−1 なる整数類について e が有効であることと e·h>0 が同値であることを、Riemann–Roch と (K_Y−e)·h<0 から示す。

E_h={e:e²=e·K_Y=−1, e·h>0} と実際の内部 (−2) 曲線類の集合 Δ を用い、nef 錐を、正錐 C⁺ 内で境界類・E_h・Δ との非負交点を課した集合の閉包として記述する。[GHK-M] Lemmas 2.13–2.15 の証明を、負曲線の分類、正錐の有理点の十分大きな整数倍の有効性、双対錐に分ける。内部 (−2) 曲線のない二対の境界を対応させる等長変換が、一組の h と gh をともに豊富にするなら、nef 錐と豊富錐全体を対応させることを得る。

**nef 平方零の境界への適用。** 二対が内部 (−2) 曲線を持たず、δ が nef で δ²=0 とする。境界類を対応させる等長変換は有効類の半群と豊富錐を自動的に対応させる。e²=−1、e·δ=1 なら (K_Y−e)·δ=−1 により e は有効である。非負自己交点の曲線類の像も δ が選ぶ正錐の閉包と Riemann–Roch から有効となり、逆写像にも適用できる。負の既約曲線の有効類としての不可分性から実際の曲線類が対応し、Nakai–Moishezon で豊富類が対応する。この錐保存自体には δ の原始性は不要である。

*Needs:* 2.1–2.4。正錐、有効類、曲線の交点。周期の一致は本項の仮定ではない。

### 4.2 節点補助模型と例外曲線配置

内部 (−2) 曲線のない二つの Looijenga 対と、境界類および豊富錐を対応させる等長変換 g を取る。g を、対応する節点 blowup の Picard 群へ、全変換上では g、新しい例外類上では対応する例外類を送る写像として延長する。1 組の豊富類 h と gh に対して Nπ*h−E とその像がともに豊富となる N を選び、この延長が補助模型の豊富錐を対応させることを証明する。

補助模型では、固定した正錐成分、e²=e·K=−1 かつ選んだ豊富類 h と正に交わる例外類、境界類、実際の内部 (−2) 曲線類から nef 錐を記述する。具体的には、正錐 C⁺ 内でこれら全てとの非負交点を課した集合の閉包が nef 錐となる。既に選んだ h と gh がともに豊富であることにより、数値的例外類の集合も対応する。[GHK-M] Lemmas 2.13–2.15 と Lemma 4.5 の特殊形として証明する。節点 blowup は内部 (−2) 曲線を新設しない。豊富錐の対応は有効曲線錐の閉包の極線を対応させる。移された例外類の有効性と平方 −1 の原始性により、その有効分解が単一の既約曲線となることを証明する。負曲線の有効代表の一意性と非負交点から、一方の互いに素な内部 (−1) 曲線配置が他方の同じ配置へ移る。nef な δ を補助模型で再利用しない。

*Needs:* 2.1–2.4、4.1。例外曲線の数値的判定、曲面の錐と縮約。証明の構成は [GHK-M] Theorem 4.7 の証明冒頭に対応する。

### 4.3 トーリック模型と中心の再構成

有理反標準サイクル対に q(Y,D)=rank Pic(Y)+2−#D を定める。内部 blowup で q が 1 増え、節点 blowup で不変となることを証明する。2.5 の模型存在から q≥0 と、q=0 なら対がトーリックであることを示す。後者では内部中心数が零の模型から、扇の逆細分で節点縮約を降ろす。

トーリック対の向き付き境界自己交点列から扇を整数線形同型まで復元する。隣接射線 `u_{j−1},uⱼ,u_{j+1}` に対する `u_{j−1}+(Dⱼ²)uⱼ+u_{j+1}=0` を用いる。同じトーリック組合せ型の二つの blowup 表示の周期が一致するとき、中心は同時トーラス平行移動まで一致し、標識と境界に適合する対の同型が存在することを証明する。[GHK-M] Remark 2.4、Proposition 2.9、Corollary 2.10 の内容を、この有限表示で構成する。

*Needs:* 2.2、2.5、3.2–3.4。扇の漸化式、指標の完全列、曲線の収縮。

### 4.4 根のない対の Torelli 定理

同じ境界成分数 n の二つの Looijenga 対 (Y₀,D₀)、(Y₁,D₁) が内部 (−2) 曲線を持たないとする。η∈{±1} と境界の順像 j を指定し、格子等長変換 g:Pic(Y₁)→Pic(Y₀) が次を満たすと仮定する。

    g[D₁,l]=[D₀,η(l−j)],
    g(Ample(Y₁))=Ample(Y₀),
    a₁(x)=a₀(gx)^η  (x∈D₁⊥).

引き戻し g、境界順像 j、向き η を持つ対の同型 ψ:Y₀→Y₁ が存在することを証明する。n≤2 の節点・枝の向きも指定する。η=1 では 4.2–4.3 により片側の節点補助模型と内部例外配置を他方へ移して収縮し、q=0 からトーリック性を得て、扇と周期から中心を再構成する。η=−1 は一方の境界の向きを反転して η=1 に帰着する。

標識付き変形型の一致を別の仮定として要求しない。[GHK-M] Theorem 1.8 の証明の generic な部分をこの構成で実装し、その結論を構造のフィールドとして受け取らない。同型自身の一意性は主張せず、差の群は 4.5 で扱う。

**対象対への系。** 原始的 nef 平方零の対象対では 4.1 が豊富錐の対応を与えるため、境界対応と周期の等式だけを入力にして同じ同型を得る。一般版とこの系を別定理として公開する。[補足 D](#d-必要な周期再構成) に証明経路を記す。

*Needs:* 3.4、4.1–4.3。向きと境界番号の対応。一般の根壁付き Torelli は含めない。

### 4.5 Picard 自明自己同型

一般の Looijenga 対に、3.1 の内部中心が相異なるトーリック表示を指定する。向きを保ち、**各境界成分を固定し**、Picard 群に自明に作用する自己同型の群は J=Hom(N/H,ℂ×) に同型であることを証明する。rank H=2 は仮定せず、J の有限性はその追加条件下の系とする。

節点・枝の対応から節点 blowup へ持ち上げ、内部 (−1) 曲線の唯一の有効代表を保存することからトーリック面へ降ろす。境界成分を各々保つ自己同型のトーラス上の単項式線形部分は全原始射線を固定して恒等となり、残りは平行移動である。中心の保存が H 上の指標の自明性を与える。逆に J の平行移動は各中心を固定して blowup へ持ち上がる。この両対応が群演算に適合することを証明する。[GHK-M] Proposition 2.6 の toric model による証明に対応する。

対象対では境界類の一次独立性から、Picard 自明な自己同型は各境界成分を固定する。従って上の条件のうち成分固定を落とした系を得る。一般の対ではこの系は成立しない。例えば ℙ¹×ℙ¹ のトーラスの反転は向きと Picard 群を保つが、対向する境界成分を交換する。

*Needs:* 2.2、2.5、3.1–3.3。対象対への系には 1.1、2.6。

### Examples

**Checks.** e²=−1、eδ=1 では χ(O(e))=1、δ·(K−e)=−1 で、e の有効性が従う。内部 (−2) 曲線を持つ場合にはその類の反射が境界・δ を固定しても有効類を負に移すので、4.1 の仮定を外せない。J の非自明元は Picard 作用を変えず、同型自身の一意性を否定する。

### Dependencies

4.1 の一般の錐記述 → 4.2、2.5 と 3.2–3.4 → 4.3、4.2–4.3 → 4.4。4.1 の平方零の系は 4.4 の対象対への適用で使う。4.5 は 4.4 の存在定理を必要としない。曲面の自己同型群とクラスター群の同定はこのレイヤーでは行わない。

## Layer 5: 表示変更とクラスター変異

### 5.1 指定された双有理写像の因数分解

一つの Looijenga 対からの指定済みの二つのトーリック収縮 p,p′ を取る。双有理写像 p′p⁻¹ を、トーリック blowup/down、Hirzebruch 曲面の基本変換、トーリック同型の有限列に分解する。各部分合成と p の合成は、始域のある節点 blowup 上で正則であり、有限個の全部分合成に共通の節点細分を取れることを証明する。[HKL] Appendix, Lutz Theorem 8.4 の主張をこの特殊形で実装する。

証明を、同 Appendix の Definitions 8.5・8.10 の Sarkisov degree、多重度の境界制約（Proposition 8.7）、高多重度基点と F₀・F₁ の例外（Lemma 8.8）、基本変換の公式（Lemma 8.9）、F₀ に必要な不等式とその証明中の二つの数値恒等式（Lemma 8.12）、有限リンク列による減少（Proposition 8.11）に分ける。ℙ² または F_a から ℙ² への写像に帰着し、移動線形系の λ と全基点多重度の和 M に対して (6λ,M)∈ℕ² の辞書式順を用いる。減少は選ばれた有限ブロック全体について証明し、準備のトーリック操作の一段ごとには要求しない。停止時の境界を保つ同型を最後に分離する。

さらに Theorem 8.4 の証明で各部分合成の正則性を追跡する。共通解消の存在や「模型の集合が連結」という弱い存在だけで、指定された写像の因数分解を置き換えない。[補足 E](#e-因数分解から語への橋渡し) に減少指標と語への橋渡しを記す。

*Needs:* 2.2、2.4–2.5。共通解消、Hirzebruch 面の ruling、境界を保つ双有理写像。

### 5.2 正則な対数的射と指定された表示変更

**正則な射の正規化。** Looijenga 対 (Z,D_Z)、滑らかな完備トーリック対 (T,D_T)、双有理射 h:Z→T を取る。トーリック対数二形式 ω_T が div(h*ω_T)=−D_Z を満たすとき、トーリック節点細分 r:S→T と ordered internal blowup の逆列 π:Z→S を構成して h=r∘π を得る。中心、ラベル、近接中心の順序を出力に含める。この定理に平方零・根の不存在・クラスター語は不要である。

点 blowup への分解と二形式の位数から境界外の中心を除き、節点 blowup を、それ以前の異なる滑らかな境界点の操作と交換して先へ移す。新境界上の中心はその節点操作の後に残す。S の境界射線 u_C は各境界成分 C における ord_C(h*zʰ)=det(h,u_C) と巡回順から回収する。正規化の等式は元の指定された射 h について証明する。

**指定された基本変換の比較。** h:Z→T、h′:Z→T′ が上の条件を満たし、指定された非トーリック基本変換 φ:T⇢T′ に対して h′=φ∘h が有理写像として成立するとする。共通のトーリック細分の後で、φ の中心 p が source の内部中心列に現れることを示す。現れなければ h は p 近傍で同型となり、φ∘h の基点が残ることに反する。

p 上の最初の中心 k を相異なる点の操作との交換で取り出し、基本変換後の残る中心を共通解消で運ぶ。同一点の近接中心の相対順序を保ち、正規化前後の射の三角形と、φ を含む有理写像の四角形が可換であることを出力する。反対境界の同じ ruling fibre 上に中心がある場合は、共通解消上の ordered な近接中心列として扱う。トーリック基本変換は節点操作として別に扱い、内部中心の存在を要求しない。

5.1 の各正則な部分合成へこの二定理を適用し、指定された同型そのものを表示変更へ移す。各表示変更から X 変異と Picard 引き戻しへの比較は 5.4 の局所定理で与える。[補足 E](#e-因数分解から語への橋渡し) に証明を記す。

*Needs:* 2.1–2.2、2.5、3.1、5.1。境界付値、単純極を持ち零を持たない対数二形式。

### 5.3 終端ラベル同定の整数性

対象対の二つのトーリック表示の電荷列が、ラベル同定後に同じ交換行列を持つとする。まず H₁≅H₂ を 0.4 の核によって構成する。次にこの同型が全格子 N₁≅N₂ へ延長することを証明する。

s=1 は H=N による。s=p=2,3 では H/pH 内の直線 pN/pH が全電荷の剰余が避ける唯一の直線となることを証明する。p=2 は射影直線の三点のうち電荷が少なくとも二点を占めることによる。p=3 は n=9、m=3、K=ℤδ と 3.2 の合同式から、三つの電荷が射影直線の相異なる三点を占めることを示す。残る直線の逆像が pN を復元する。[補足 C](#c-終端ラベル同定の延長) に完全な有限計算を記す。

この整数同型を扇の共通細分へ延ばし、相異なる中心の順序を合わせ、2.6 の最小化の一意性から最小対の同型を得る。任意の有限指数 H⊂N でこの延長が成立するとは主張しない。

*Needs:* 0.4、1.1、2.5–2.6、3.1–3.2。原始電荷、s²|n、m=12−n。

### 5.4 一変異の中心・有理写像・全 Picard 作用

一般の順序付きトーリック表示と内部中心 k を取る。必要な節点細分の後で、扇 Σ が v=vₖ と −v の両射線を持つとする。

    tₖ(u)=u+[det(u,v)]₊v,  Σ′=tₖ(Σ),
    v′ₖ=−vₖ,  v′ᵢ=tₖ(vᵢ) (i≠k),
    Cₖ(c)ₖ=cₖ⁻¹,  Cₖ(c)ᵢ=cᵢcₖ^[εᵢₖ]₊ (i≠k).

tₖ は二つの半平面で行列式 1 の整数線形写像となり、Σ′ が滑らかな完備扇であることを証明する。新表示 P′ の順序は、k を元の射線の列から除き、反対射線の列の先頭へ入れ、他の列の順序を輸送して定める。近接中心を含む場合、k は元の点の上の最初の中心とする。Cₖ は中心トーラスの単項式同型である。二度の変異で Cₖ 自体が固定した枠の恒等になるとは主張しない。X 写像の対合性と、電荷格子の枠の変更を区別する。

zᵛ の ruling のファイバー類を `F=Σ_{det(u,v)>0}det(u,v)[D̄_u]` とする。トーリック境界類を全引き戻し、Eᵢ を全変換例外類として、整数写像 Iₖ:L̃_P′→L̃_P を次の生成元公式で構成する。

    Iₖ(E′ₖ)=F−Eₖ,  Iₖ(E′ᵢ)=Eᵢ (i≠k),
    Iₖ([D̄′_{tₖ(u)}])=[D̄_u]               (u≠v,−v),
    Iₖ([D̄′_v])=[D̄_v]−Eₖ,
    Iₖ([D̄′_{−v}])=[D̄_{−v}]+F−Eₖ.

主因子の関係を保つことと、共通 blowup 上の引き戻しによる等長同型であることを証明する。境界の固有変換 `[D̂_u]=[D̄_u]−Σ_{vᵢ=u}Eᵢ` は対応する固有変換へ送られる。全 Picard 作用を K 上の作用だけの定義に置き換えない。

同一射線上の中心が相異なり、vᵢ=−vₖ なら cᵢcₖ≠1 を満たす非空開集合 Uₖ 上で、中心を blowup して ruling のファイバーを縮約することにより、向きを保つ対の同型 Ψₖ,c:Ỹ_P(c)≅Ỹ_P′(Cₖ(c)) を得る。この同型について、以下を同時に証明する。

    Ψₖ,c* z′ʰ = zʰ(1+cₖzᵛᵏ)^(−det(h,vₖ)),
    μ̃_{P,c} ∘ Iₖ = Ψₖ,c* ∘ μ̃_{P′,Cₖ(c)},
    ev_P′(Cₖ(c),Ψₖ,c(z)) = F_μₖ(ev_P(c,z)),
    Iₖ ∘ ι̃_P′ = ι̃_P ∘ (Bₖ|_K).

評価式は共通の有理定義域で読む。最後の式は 3.2 の補助模型上の境界直交類への同定であり、例外類との交点を計算して導く。Picard 作用が c に依存しないことは二番目の式の帰結である。近接中心を含む 5.2 の比較では同じ共通解消の計算を ordered な列に適用し、一般位置の公式との一致を証明する。

対象対への節点縮約が指定されている場合は、境界固有変換と元の δ の全変換を保存することから Ψₖ,c と Iₖ を最小対へ降ろす。誘導された L_P′→L_P の写像については、同じ比較を ι_P′ と ι_P で述べる。[GHK-C] (1.4)、Lemma 3.2、Theorem 5.6 の証明が局所計算の参照先であり、全生成元の比較は [補足 E](#e-因数分解から語への橋渡し) で展開する。

### 5.5 語の実現、終端同定、境界付値

5.4 の局所実現、ラベル置換、トーラスの枠変更、節点細分を合成する。対象対の表示を始点とする任意の有限の反転なしの語について、中心の非空開集合、単項式中心写像、各中心での対の同型、中心に依存しない全 Picard 同型を得る。合成は中心写像について実行順、Picard 引き戻しについて逆順となり、標識と評価の二つの可換式を保つことを証明する。

## Layer 6: 向きを保つ群の決定

### 6.0 幾何的実現の比較と合成

一般の二つの固定表示 P₀,P₁ に対し、X 双有理写像 F:𝕋(A₀)⇢𝕋(A₁) の幾何的実現を次の具体的データと等式で定める。表示には電荷ラベル、標準の Picard 標識、周期の向きの規約を含める。

- 非空 Zariski 開集合 U⊂𝕋(A₀) と、U 上で正則かつ支配的な中心写像 C:U→𝕋(A₁)。
- 各 c∈U(ℂ) での実際の対の同型 Ψ_c:Y_P₀(c)≅Y_P₁(C(c))。
- 中心に依存しない格子等長同型 I:L_P₁→L_P₀、指定した境界成分対応 β、節点・枝も含む向き η。各 Ψ_c は同じ β と η を実現する。
- 標識と Picard 引き戻し、評価と X 写像の可換性。

    μ_{P₀,c}∘I = Ψ_c*∘μ_{P₁,C(c)},
    F(ev_P₀(c,z)) = ev_P₁(C(c),Ψ_c(z)).

二番目の式は共通の有理定義域上の等式である。これは主同型を仮定する構造ではなく、スキーム同型と既存の引き戻しの整合性を束ねたものである。5.4–5.5 は該当する実現を構成する。

**同じ X 写像の比較。** 同じ P₀,P₁ の二つの実現で F₁=F₂ とし、終域の rank H₁=2 を仮定する。共通開集合の中心で終域の K 指標が一致するため、3.3 のトーラス平行移動で中心を整列できる。差の同型は H₁ の全指標を固定し、有限被覆の計算により J₁ に属する。従って I、β、η が全て一致する。この方向では有限指数の仮定を保持する。

**同じ格子・境界作用の比較。** 同じ P₀,P₁ の二つの実現で I、β、η が一致するとする。中心写像の支配性で両終端を同時に相異なる中心の開集合へ入れる。3.4 の周期の自然性から終端の K 指標が一致し、中心整列後の差は 4.5 により J₁ に属する。3.3 の評価写像の支配性から F₁=F₂ を得る。この方向に J₁ の有限性は不要である。η を条件から落とさない。対象対では β は I から回収できるが、n≤2 では η は別のデータである。

**基本 API。** 開集合への制限、恒等実現、実現の合成を構成する。二つの実現の合成の定義域は U₀₁∩C₀₁⁻¹(U₁₂) であり、中心写像の支配性により非空となる。合成式は C₀₂=C₁₂∘C₀₁、I₀₂=I₀₁∘I₁₂、β₀₂=β₁₂∘β₀₁、η₀₂=η₀₁η₁₂ である。中心写像が双有理なら開集合を縮小して逆実現も構成する。選択の比較とこれらの操作の整合性を証明する。

*Needs:* 0.1、3.1–3.4、4.5。語についての実現の構成は 5.4–5.5 から供給されるが、比較定理自体は語を仮定しない。証明の有限被覆と自己同型核の計算は [補足 F](#f-向きを保つ群の全単射)。

### 6.1 有理写像から Picard 作用へ

反転なしのループの 5.5 による実現から、中心に依存しない g∈G⁺ を取る。6.0 の同じ X 写像の比較により、g は有理写像だけで決まり、終端格子の同定・共通細分・中心整列の選択にも依存しない。

*Needs:* 0.3–0.4、1.3、3.2、5.3–5.5、6.0。

### 6.2 単射性

*Needs:* 1.1、2.6、6.0–6.1。

### 6.3 全射性

任意の g∈G⁺ を取る。3.5 により根を避ける周期を取り、3.4 により a₁=a₀∘g|_K を満たす両端の中心を固定した表示 P で実現する。4.4 により引き戻し g の対の同型を得る。終域のトーリック収縮をこの同型で始域へ引き戻し、5.1–5.2 を指定された写像に適用する。

各基本変換は 5.4 の変異、トーリック格子同型と中心ラベルの変更は置換、節点細分は恒等の X 写像となる。平行移動は中心の枠変更に吸収される。両端が P なので得た語はループで、Picard 作用は指定した g である。この一点で定義された有限語は非空 Zariski 開集合で実現できる。

*Needs:* 3.4–3.5、4.4、5.1–5.5、6.1。一般のモジュライ空間や全群一致の外部仮定を使わない。

### 6.4 向きを保つ群の同定

6.1–6.3 を合わせて Γᵒᵖ≅G⁺ を構成する。写像・逆写像の両合成、基点表示を変えるときの語による共役と Picard 標識変更の整合性を証明する。最後の整合性は、同じ最小対の表示変更の語が与えられた場合の主張とし、任意の二つの seed の間の写像を仮定しない。

*Needs:* 6.1–6.3。群同型と共役。

## Layer 7: 符号付き群と関係式の完全判定

### 7.1 向きの反転と奇の語の存在

同じ曲面・同じ幾何的中心・同じ全例外類に、反対の格子向きを与えた表示 P̄ を作る。det̄=−det、z̄ʰ=(zʰ)⁻¹ なので、中心パラメータと X 座標は c̄=c⁻¹、X̄=X⁻¹ となる。同じ曲面の恒等写像を両表示の間で読むと、ς の実現を得る。この生の表示反転の Picard 作用は I=id、向きは η=−1、周期は逆数化であることを証明する。標識変更 g₀ とは区別する。

対象対の固定表示 P で根を避ける周期 a₀ を選び、

    a₁(x)=a₀(g₀x)⁻¹

を 3.4 により同じ表示の中心として実現する。4.4 の符号を含む系から、Picard 引き戻し g₀、向き −1、境界順像 j=2j₀ の同型を得る。最初に上の表示反転を入れると、残りは P̄ から P への向きを保つ指定された同型となる。5.1–5.5 により −ε から ε へ戻る反転なしの語 p₀ を得る。

ς の後に p₀ を続けた奇のループ o は Picard 作用 g₀ を持つ。奇のループの存在を符号射影の全射性の仮定に置かない。境界を鏡映で付け替え、標識を μg₀ として同じ議論を読む場合も、表示反転の I=id と標識変更の g₀ を一度ずつ適用する。

*Needs:* 0.3、1.2、3.4–3.5、4.4、5.1–5.5、6.4。証明は [補足 G](#g-符号付き拡大)。

### 7.2 偶奇の降下と主同型

0.3 の交換関係と 7.1 の o を用いて、任意の奇の語の写像を偶の語の写像と F_o の合成で表す。これにより任意の符号付きループを一般の中心で最小対の同型として実現する。同じ X 写像の二つの実現は 6.0 の比較定理から同じ向きを持つため、偶奇が Γ̃ の元だけで決まることを証明する。

実現の Picard 作用を g_F、向きの符号を η_F として、

    Θ: Γ̃ᵒᵖ ≅ Ĝ,  Θ(F)=(g_F,η_F)

を構成する。点の写像の記法では Θ(F∘F′)=Θ(F′)Θ(F) である。単射性は η=1 の核に対する 6.2、全射性は 6.3 と (g₀,−1) の実現による。元の曲面の周期を保存するという追加仮定を群の定義に入れない。

*Needs:* 0.3、1.3、6.0–6.4、7.1。

### 7.3 分裂と小さい境界の中心

η:Γ̃→{±1} の核が Γ で、Γ の指数が 2 であることを証明する。Θ⁻¹(g₀,−1) は対合であり、1.3 の半直積を Γ̃ へ移す。n≥3 では Θ と O(L) への射影が、境界を二面体置換する等長群への反同型となる。

n≤2 では z=Θ⁻¹(id,−1) が非自明な中心的対合で、Γ̃≅Γ×⟨z⟩ となることを証明する。z を全座標の反転 ς だけで定義しない。ς 単独は ε≠0 のときループではない。

*Needs:* 1.3、7.2。

### 7.4 Picard 作用と Casimir 作用

Θ(F)=(g,η) に対し、全 x∈K について w_F(x)=ηg(x)、`Xˣ∘F=X^{ηg(x)}` を証明する。変異では 5.4、置換では 3.2 の自然性、反転では幾何的作用 id と単項式作用 −id を比較してから合成する。従って c′|_K=c|_K∘(ηg|_K)、w_F(δ)=ηδ である。

Γ の K 作用の像を W と書き、ι_K(κ)=κ−2(κ·f)δ と置くと、符号付きの単項式作用の像は W ⊔ Wι_K である。ι_K²=id、ι_Kδ=−δ、K/ℤδ 上では恒等であることを証明する。W を Weyl 群の全型分類で表すことはこの主張に必要ない。単項式作用の核は Γ に含まれる。n≤2 の中心的対合 z は全 Casimir を逆数にするが、幾何的 Picard 作用は恒等である。

*Needs:* 0.4、1.2、3.2、5.4、6.4、7.1–7.3。

### 7.5 関係式の完全な整数不変量

符号付きループ w に、偶奇の符号 η_w、0.4 の整同型 w_K、0.5 の付値列が指定する境界の順像 D₀↦D_j を対応させる。反転では付値列の符号を変える。二つのループについて、次が同値であることを証明する。

    F_{w₁}=F_{w₂}
      ⇔ η_{w₁}=η_{w₂},  (w₁)_K=(w₂)_K,  j_{w₁}=j_{w₂}.

Θ(F)=(g,η) との対応は w_K=ηg|_K、`gD_l=D_{η(l−j)}` である。必要性は写像の単項式・付値の作用と偶奇の降下、十分性は 1.4 と 7.2 から示す。付値列の終値を探す集合は、終域の最小境界成分を表す有限個の射線である。整数基底上の有限行列の等号へ帰着するため、語の等価性は決定可能であることも帰結として証明する。

主張はループについてであり、指定した特殊周期のファイバー上の任意の有理写像の等号を、この判定と同一視しない。

*Needs:* 0.4–0.5、1.4、3.2、5.5、7.2–7.4。

### Examples

## Layer 8: Cremona 等長変換と具体的な群

### 8.1 Cremona 等長変換群との比較

Cr(Y) を、交点形式、標準類、有効類の半群を保つ Picard 群の自己同型群と定義する。[Sakai] §4 の (Cr1)–(Cr3) による。内部 (−2) 曲線のない対象対では、Cr(Y) が Ĝ→O(L) の像に等しいことを証明する。

Ĝ の像から Cr(Y) への包含は 4.1 による。逆包含では負の既約曲線の有効類の不可分解性を用いる。n≥2 で自己交点 −2 の既約曲線は境界成分に限られるため、それらの交点グラフの置換を得る。n≥3 ではその置換は二面体群、n=2 では任意の二成分の置換が回転となる。n=1 では唯一の境界類 δ=−K が固定される。

従って n≥3 では Γ̃ᵒᵖ≅Cr(Y) を証明する。n≤2 では Γ̃ᵒᵖ≅Cr(Y)×C₂ および Γᵒᵖ≅Cr(Y) を証明する。群の決定は 7.2 によるもので、[Sakai] Theorem 26 の型表から全群一致を仮定しない。

*Needs:* 2.3–2.4、4.1、7.2–7.3。

### 8.2 A₇⁽¹⁾′ の四頂点の種

ℙ¹×ℙ¹ の四つのトーリック節点を吹いた八角形の扇を取り、対角方向の四つの新境界成分をそれぞれ一つの内部点で吹く。全境界は八成分で各自己交点 −2、δ は原始的 nef 平方零であることを証明する。電荷は v₁=(1,1)、v₂=(−1,1)、v₃=−v₁、v₄=−v₂ で、ε₁₂=ε₂₃=ε₃₄=ε₄₁=2、ε₁₃=ε₂₄=0、s=2 となる。

K の基底 κ₁=e₁+e₃、κ₂=e₂+e₄ と δ=κ₁+κ₂ を使い、次の三つのループを構成する。語は書かれた順に実行する。

    π₂: σ(i)=i−1 による置換。
    T:  μ₁, μ₃, (1,2)(3,4)。
    π₁: ς, (1,3)。

π₂ は κ₁↦−κ₁+δ、T は κ₁↦κ₁+δ、π₁ は K 上 −id を誘導する。半回転 π₂² は K 上恒等だが境界を四成分回転する。具体的な Picard 格子上で、K 上恒等な G⁺ の元が恒等と半回転だけであることを証明する。[補足 H](#h-四頂点の生成元の完全性) の半整数係数による排除を使う。

δ を固定する K の等長変換は κ₁↦±κ₁+lδ の形なので、π₂ と T の像が可能な全像を生成し、その生成群が核も含む。これと 6.4 から Γ=⟨π₂,T⟩、7.2 から Γ̃=⟨π₁,π₂,T⟩ を証明する。[BGM] (3.1) の三生成元との比較は X=y⁻¹ の共役で行う。単射の構成だけで生成の完備性を結論しない。

*Needs:* 0.2–0.5、2.2、2.5–2.6、3.2、6.4、7.2、7.4–7.5。具体的な階数 10 の整数格子計算。

### 8.3 一成分境界の中心的対合

ℙ² の三境界直線の射線 (1,0)、(0,1)、(−1,−1) 上に、それぞれ 2、3、6 個の相異なる内部中心を置く。最初の二直線の固有変換を順に縮約すると、最後の直線は自己交点 0 の既約結節反標準曲線になることを証明する。最初の二直線と交わらない内部例外曲線が δ と交点 1 を持つため、δ は原始的である。

11 ラベルの種で o=(ς,μ₁,μ₂)、z=(ς,μ₁,μ₂,(1,2)) を構成する。電荷核の条件は x₁+x₂=x₃+x₄+x₅=x₆+⋯+x₁₁ であり、δ=(3,3,2,2,2,1,1,1,1,1,1) となる。z は K 上 −id、n=1 なので Θ(z)=(id,−1) であり、全群の中心的対合であることを証明する。

*Needs:* 0.2–0.4、2.2–2.6、3.2、7.2–7.5。境界の自己節点の二枝を区別する規約。

## Proof details

以下では、各レイヤーの特殊命題と橋渡しを展開する。L、M、K、δ、P、N、A、H と向きの規約は Conventions に従う。曲面論の基礎命題は Layer 2 の実装目標であり、この節ではその結論を入力とする。各証明は実装経路を与えるものであり、同じ仮定と結論を持つ別の証明を妨げない。

### A. 境界格子の整数計算

#### サイクルの核と飽和

サイクル行列 C の二次形式は、n≥1 に対して −Σ(qᵢ−qᵢ₊₁)² である。n=1 では零、n=2 では −2(q₀−q₁)² となる。従って ℚ 上の核は定数列である。ΣqᵢDᵢ=0 なら Cq=0 だから qᵢ=q、そして qδ=0 である。δ は原始的非零元なので q=0、境界類は独立である。これから M_Q∩(M⊥)_Q=ℚδ と M_Q+(M⊥)_Q=δ⊥_Q が従う。

Mˢ=(M⊗ℚ)∩L、T=Mˢ/M と置く。x=ΣqⱼDⱼ∈Mˢ に対し χⱼ(x)=qⱼ mod ℤ を定める。x·Dⱼ が整数なので、n≥3 では χⱼ₋₁−2χⱼ+χⱼ₊₁=0、n=2 では 2(χ₁−χ₀)=0 である。従って τ=χ₁−χ₀ により χⱼ=χ₀+jτ、nτ=0 となる。n=1 では δ の原始性から T=0 である。

τ(x)=0 なら x−q₀δ∈M であり、q₀δ∈L から q₀∈ℤ、従って x∈M である。よって τ:T→ℚ/ℤ は単射で、T は位数 t|n の巡回群となる。T の生成元 x₀ に対して τ(x₀) は位数 t、χ₀(x₀) は t 分の整数である。従って 0≤j₀<t で χ₀(x₀)+j₀τ(x₀)=0 となるものがあり、`χ_{j₀}` は T 全体で零である。

この j₀ の係数を読む線形形式 Dⱼ↦[j=j₀] は Mˢ 上で整数値を取る。Mˢ は L の原始部分加群なので、この形式は L 上の整数線形形式へ延びる。単模性により、それはある f₁∈L との交点で表される。f₁·δ=1 であり、δ の特性元条件から f₁² は奇数である。そこで

    f=f₁−((f₁²+1)/2)δ

と置くと、f·Dⱼ=[j=j₀]、f²=−1 となる。この構成は f の有効性も曲線としての実現も用いない。

#### 鏡映の構成

U=ℤδ⊕ℤf の Gram 行列は [[0,1],[1,−1]] で行列式 −1 だから L=U⊕U⊥ である。`αᵢ=D_{j₀+i}`、1≤i<n は U⊥ 内の負の `A_{n−1}` 型の単純根である。反射 sᵢ(x)=x+(x·αᵢ)αᵢ は格子等長変換となる。

Q=Σℤαᵢ を ℤⁿ の座標和零の格子へ αᵢ↦bᵢ−bᵢ₊₁ で同定し、形式を通常の内積の負とする。sᵢ は隣接互換、Q⊥ では恒等である。従って順序反転の置換に対応する w₀ は一意に定まり、`w₀αᵢ=−α_{n−i}`、w₀²=id となる。n=1 では Q=0、w₀=id とする。

    g₀=id_U⊕(−w₀|_{U⊥})

は対合的等長変換である。`g₀Dⱼ=D_{2j₀−j}` は j≠j₀ について上式から、j=j₀ について δ の保存から従う。κ∈M⊥ なら κ·δ=0 なので κ=(κ·f)δ+κ⊥ と書ける。κ⊥ は全 αᵢ に直交するため w₀κ⊥=κ⊥、従って

    g₀κ=−κ+2(κ·f)δ.

これが Suggested.lean の格子定理の証明である。

#### 指数の制約

L の符号数が (1,9) の場合、U⊥ は階数 8 の負定値偶単模格子である。δ⊥/ℤδ を U⊥ へ同定すると、M/ℤδ は `A_{n−1}(−1)` で、その行列式の絶対値は n となる。M/ℤδ の飽和指数も t なので

    n=t² · |disc((M/ℤδ)ˢ)|.

右の残りの因子は非零整数であるから t²|n。階数から n−1≤8、従って n≤9 となる。E₈ 格子の分類や、その全等長群の計算は不要である。

#### 制限と境界像による一意性

等長変換 h が M⊥ と全 Dⱼ を固定すると、h は δ⊥_Q=M_Q+(M⊥)_Q を点ごとに固定する。f·δ=1 なる f に対して、hf−f は δ⊥_Q の全元に直交するため aδ と書ける。平方の保存から

    0=(f+aδ)²−f²=2a,

よって hf=f、h=id となる。従って格子作用を区別するには M⊥ 上の作用と境界類の像で足りる。向きの符号 η と D₀ の順像 j が分かれば、引き戻しの全境界像は `D_l↦D_{η(l−j)}` で回収できる。

### B. 電荷と有限指数

#### 核上の単項式の輸送

変異後の電荷核の元 x∈ker(v′)⊂ker(ε′) に対し、k 行目の核条件は `Σ_{i≠k}εᵢₖxᵢ=0` である。従って変異公式から

    ∏_i(X′ᵢ)^xᵢ
      = (∏_{i≠k}Xᵢ^xᵢ) Xₖ^(−xₖ+Σ_{i≠k}[εᵢₖ]₊xᵢ)
        ·(1+Xₖ)^(−Σ_{i≠k}εᵢₖxᵢ)
      = X^{Bₖx}.

Bₖ が核を核へ写すことは v′=v∘Bₖ から従う。置換は指数を同じ置換で移し、反転は全指数を負にする。各段の核を始域・終域として合成すれば、語全体の単項式作用が得られる。

#### 境界直交類の整数表示

補助模型を、滑らかなトーリック面 Ȳ の内部 blowup の有限列として書く。全変換の例外類 Eᵢ を用い、類を H_x−ΣxᵢEᵢ と表す。境界射線 u 上の固有変換との交点が零になる条件は

    H_x·D̄_u=Σ_{vᵢ=u}xᵢ.

滑らかな完備扇のトーリック交点表示では、指定した多重次数 d_u が因子類の次数となる必要十分条件は Σd_u u=0 である。これは隣接射線を基底とする支持関数の整数漸化式、またはトーリック Picard 表示の双対から証明できる。従って H_x は x∈ker(v) に対して一意に存在する。逆に、境界直交類の Eᵢ との交点が xᵢ である。これにより補助模型上の境界直交格子と K が同定される。

節点 blowup では Picard に新しい例外類が直交和として加わり、境界の生成群にも同じ例外類が加わる。境界との直交条件はその新成分を零にするため、上の同定は最小対へ降りる。

#### ノルムの必要な合同式

電荷を境界に沿う時計回り順、すなわち det が定める正の向きの逆順に並べる。Σxᵢvᵢ=0 なので、辺 xᵢvᵢ を持つ閉じた整数辺の列を作れる。符号付き面積の交点計算、または扇の支持関数の漸化式から

    H_x²=−Σ_{i<j}det(vᵢ,vⱼ)xᵢxⱼ,
    (H_x−ΣxᵢEᵢ)²=−Σxᵢ²−Σ_{i<j}det(vᵢ,vⱼ)xᵢxⱼ

となる。辺の係数 xᵢ が負でも、両辺が同じ二次形式なので式は全整数関係に成立する。同じ射線のラベルの交換は行列式零の項しか変えない。巡回順の始点の変更による差は det(Σxᵢvᵢ,Σxᵢvᵢ) の対応項として零になる。

この符号付き式を任意のラベル順で使わず、d が全 det(vᵢ,vⱼ) を割る場合の結論

    κ²≡−Σxᵢ²  (mod d)

だけを順序に依存しない形で取り出す。

8.2 の四電荷と δ=(1,1,1,1) では、時計回り順は 1,4,3,2 であり、この式は δ²=0 を与える。番号順 1,2,3,4 をそのまま代入すると −8 になる。従って符号付き式の入力順序を型または明示的な並べ替えで保持する。

#### 境界商と電荷指数

トーリック境界が生成する Picard 表示に内部例外類を加える。境界の固有変換を零とする商では、各トーリック境界類はその上の内部全例外類の和に置き換わる。残る主因子の関係は

    Σ_i ⟨m,vᵢ⟩Eᵢ=0  (m∈N*)

である。従って補助模型の Picard 群を境界生成群で割った商は coker(v*:N*→A*) となる。節点 blowup は商を変えないので、これは L/M に等しい。以下の数値的帰結では対象対を取る。Smith 標準形により

    |tors(L/M)|=[N:H]=s.

Mˢ/M=tors(L/M) なので A 節の t が s に等しい。Picard 階数を数えると、節点 blowup 数を b として

    10+b=(n+b)−2+m,

従って m=12−n。K の階数は 10−n だから H は階数 2 である。これで s²|n と n≤9 が電荷側にも適用できる。

### C. 終端ラベル同定の延長

変異は電荷列に可逆な整数基底変更を施すので H を保つ。電荷が N を有理的に張るため ker(v)=ker(ε) である。従って二つの交換行列がラベル同定後に等しければ、同じラベルの電荷を移す H₁≅H₂ が誘導される。行列式の制限も保存される。Smith 標準形から `s=[N:H]=gcd_{i<j}|εᵢⱼ|` であるため、比較する二つの表示の s も一致する。

H の同型から N の同型への延長は一般には自動でない。B 節により s=1,2,3 だけを調べればよい。s=1 では H=N である。s=p が素数なら pH⊂pN⊂H で、

    ℓ=pN/pH⊂H/pH

は二次元の 𝔽_p 空間の直線となる。各 vᵢ は N で原始的なので、その剰余は非零で ℓ に属さない。実際 vᵢ∈pN なら vᵢ は N で p 倍に割れる。

p=2 では、電荷が H/pH を張るので射影直線の三点のうち少なくとも二点を占める。残る一点が ℓ であり、一意に復元される。

p=3 では s²|n≤9 より n=9、m=3 である。電荷の 2×2 小行列式を H の基底で取り、

    x=(det_H(v₂,v₃),det_H(v₃,v₁),det_H(v₁,v₂))

とする。電荷が H を生成するのでこれらの最大公約数は 1、x は階数一の K の原始生成元である。δ も K の原始元なので x=±δ である。det_N の全成分は 3 の倍数で、δ²=0 だから B 節の式により Σxᵢ²=0 mod 3。少なくとも一つの座標は非零で、𝔽₃ の非零平方は 1 なので三座標全てが非零となる。従って三電荷は 𝔽₃ の射影直線の相異なる三点を占める。第四の点が唯一の ℓ である。

H のラベル同型はこの特徴付けを保つため、pN を対応させ、さらに N を対応させる。その ℚ 線形延長が必要な整数格子同型となる。変異で原始性が保存されることは、各半平面で電荷の変更が行列式 1 の剪断となることから従う。

N の同型が得られた後、扇の共通の滑らかな細分を取り、同じ射線上の相異なる中心の順序を合わせる。最小対の境界の全変換は境界交点行列の原始正の零ベクトルである。係数 1 の成分が元の境界、係数が 1 より大きい成分が節点 blowup の例外集合であるため、二つの最小化の縮約集合が一致する。縮約の一意性から最小対の同型を得る。

### D. 必要な周期再構成

#### 周期と中心

節点サイクルの正規化で、多重次数零の線束を各有理成分上で自明化する。節点の接着比の積は自明化の変更で変わらず、これを Pic⁰(D)≅ℂ× の座標とする。向きの逆転は全接着比を逆に読むので逆数を与える。

B 節の類 H_x−ΣxᵢEᵢ を境界に制限すると、H_x の固定された接着比と中心 pᵢ の値の積になる。pᵢ は zᵛⁱ(pᵢ)=−cᵢ⁻¹ を満たす。二中心 c,d の比を取ると H_x の寄与と −1 の因子が消え、規約だけによる共通の符号 θ について

    a_{P,c}(x)/a_{P,d}(x)=((c/d)^x)^θ

を得る。基準中心 d を取って `χ_P(x)=a_{P,d}(x)/(d^x)^θ` と置く。この比の公式は χ_P の基準中心からの独立性を与え、H_x と制限の加法性から χ_P は指標となる。

    a_{P,c}(x)=χ_P(x)·(c^x)^θ.

A/K≅H は自由なので K は A の直和因子であり、指標の制限 T(A)→T(K) は全射である。従って周期写像も全射となる。向き η の対の同型による引き戻しは接着比の積を η 乗へ移すため、a₁(x)=a₀(Ψ*x)^η が得られる。

同じ周期を持つ同じトーリック組合せ型の中心は、χ_P を消去すると同じ K 指標を持つ。比は H の指標で、それを N へ延長して平行移動すれば中心が対応する。これは [GHK-M] Proposition 2.9 と Corollary 2.10 の中心再構成の特殊形である。

#### 根のない点

対象対では δ は L で原始的で、K は L の部分加群だから K/ℤδ に捩れはない。整数基底 δ,β₁,…,β_r を選び、相異なる奇素数 pᵢ に対して

    a(n₀δ+Σnᵢβᵢ)=2^(−n₀)∏pᵢ^{nᵢ}

と置く。素因数の指数比較から a は単射である。従って全ての非零平方 −2 類と、その全ての δ 平行移動で値 1 を取らない。a/χ_P と θ を用いて中心を選べる。内部 (−2) 曲線の類は境界上の自明線束を与えるので、そのような中心では内部 (−2) 曲線が存在しない。

この議論は一点の存在である。全根を避ける集合が Zariski 開であるという主張を含まない。選ばれた一点から有限語を得た後、その語に必要な有限個の非衝突条件だけが非空 Zariski 開集合を定める。

#### 有効錐と補助模型

nef な δ に対して、e²=−1、eδ=1 なら χ(O(e))=1、(K−e)δ=−1 である。Serre 双対性と Riemann–Roch から e は有効となる。境界以外の負の既約曲線 C は、Cδ≥0 と算術随伴から、内部 (−2) 曲線または (−1) 曲線である。内部 (−2) 曲線がなければ後者だけが残る。

境界類を対応させる等長変換 g は δ を固定するため、豊富類を含む正錐成分を保つ。非負自己交点の有効曲線の像 x もこの正錐の閉包にあり、豊富類 h に対して h·x>0、xδ≥0 となる。χ(O(x))≥1 と h·(K−x)<0 から x は有効である。負の曲線の像の有効性は前段による。逆写像にも適用して、有効半群が対応する。Nakai–Moishezon から豊富類も対応する。

一般の根のない Looijenga 対について、ここからは豊富錐を対応させる g を入力にしてよい。対象対の場合は前段がその条件を供給する。対応する節点を吹くとき、g を新例外類の対応で延長する。既知の豊富類 h と gh に対し、十分大きな N で Nπ*h−E とその像がともに豊富になる。補助模型で上の構成から得た一組の豊富類 H と gH を固定する。M̃_H={e : e²=eK=−1, e·H>0} と置くと、g は M̃_H を M̃_gH へ送る。nef 錐は、正錐 C⁺ 内で M̃_H、境界類、実際の内部 (−2) 曲線との非負交点を課した集合の閉包である。この記述は [GHK-M] Lemmas 2.13–2.15 の特殊形である。延長はこれらを対応させるため、補助模型の豊富錐を対応させる。元の δ の nef 性はここで使い直さない。

#### 指定された格子同型の実現

一方の対のトーリック模型を選ぶ。根のない対では、内部 blowup の中心が同じ境界点の上で重複すると内部 (−2) 曲線が生じるため、その例外配置は互いに素な (−1) 曲線からなる。補助模型間の錐の対応は、この例外配置を他方の実際の例外配置へ移す。両側で縮約する。

q(Y,D)=rank Pic(Y)+2−#D は内部 blowup で 1 増え、節点 blowup では不変である。トーリック模型存在から q は内部中心数であり、q=0 の対はトーリックである。従って両側の縮約先はトーリックになる。対応する境界の自己交点列から扇を再構成し、同じトーリック組合せ型に帰着する。周期の一致から中心が平行移動まで一致し、指定された格子同型を誘導する対の同型が得られる。これは [GHK-M] Theorem 1.8 の generic な証明部分を有限の構成に展開したものである。

### E. 因数分解から語への橋渡し

[HKL] Appendix の Lutz Theorem 8.4 の入力は、一つの対からの指定された二つのトーリック収縮 p,p′ である。出力は p′p⁻¹ 自体の因数分解で、各部分合成と p の合成が元の対の節点 blowup 上で正則になる。有限個の節点 blowup を共通細分 Z にまとめる。

この有限列の存在証明も形式化の対象とする。一般のトーリック両端をトーリック操作で ℙ² と Hirzebruch 面へ帰着し、F=ℙ² または F_a から ℙ² への、対数二形式を非零定数倍まで保つ双有理写像を扱う。引き戻した直線系について、F=ℙ² では次数 d に対し λ=d/3、F_a では [HKL] Definition 8.5 の係数 b に対し λ=b/2、M は近接基点も含む全基点多重度の和とする。6λ は非負整数である。

高多重度基点がある非同型の場合、Proposition 8.11 の選ぶ許されたリンクの有限ブロックの後で (6λ,M) が辞書式順に真に減少する。切断上の多重度 m>λ の場合は λ を保ち、M′=M+b−2m<M となる。ファイバー上の高多重度基点では、必要に応じて F₀ へ準備変形し、Lemma 8.12 の証明の二つの数値恒等式を用いたブロックで λ を減らす。高多重度基点がない非同型の場合は、Lemma 8.8 の F₀ の ruling 交換または F₁ の負切断縮約で λ を減らす。準備段階で M の単調性は主張しない。従って ℕ² の整礎性から有限性が従い、残る正則同型を最後のトーリック同型とする。任意の中間トーリック模型にこの degree を定義する必要はない。

各写像 hᵢ:Z→Tᵢ を点 blowup の逆列に分解する。Tᵢ のトーラスの対数二形式を引き戻すと、Z の被約境界に単純極を持ち、零因子を持たない。局所的には、極のない点の blowup は例外曲線に零を生じ、境界の滑らかな点の blowup は新例外曲線の位数を 0 にし、二つの単純極が交わる節点の blowup は新例外曲線に単純極を作る。

零因子が一度生じれば、その固有変換は最終模型まで残る。従って極のない点での blowup は起こらない。許される操作は境界の滑らかな点と節点の blowup だけとなる。両者を、局所アフィン座標で許される順序交換によって整理し、

    Z → Sᵢ → Tᵢ

と分ける。前半は内部 blowup の逆列、後半はトーリック節点細分である。Sᵢ の扇は各境界成分上の指標の付値から復元される。

隣接するトーリック blowup/down の段は、この整理の後には同じトーラス座標を持つ節点細分になる。非トーリック基本変換の中心 p は、hᵢ の内部 blowup 列に現れなければならない。現れなければ p 近傍で hᵢ は同型であり、次の部分合成が Z 上で正則になることに反する。p 上の最初の中心を他点上の中心との交換で取り出し、その例外曲線と ruling のファイバーを用いて基本変換を行う。残る中心は共通解消上で運ぶ。同一点の近接中心は順序を変えない。

#### 一変異の全 Picard 比較

反対射線を加えた扇で v=vₖ とし、tₖ(u)=u+[det(u,v)]₊v と置く。ruling のファイバー類 F は `Σ_{det(u,v)>0}det(u,v)[D̄_u]` である。5.4 の生成元公式は新しいトーリック主因子の関係を保つ。実際、その関係を Iₖ で移した差は

    det(h,v)·(Σ_{det(u,v)>0}det(u,v)[D̄_u]−F)=0

となる。従って整数写像はトーリック Picard の商に降りる。中心を blowup した共通曲面では新例外曲線は元の fibre の固有変換となり、E′ₖ=F−Eₖ を得る。二つの切断の全引き戻しはそれぞれ D̄_v−Eₖ、D̄_−v+F−Eₖ、他の境界の全引き戻しは同じ D̄_u となる。この比較で全生成元公式と等長性が証明される。近接中心があれば、さらに共通の点 blowup を施し、全変換例外類で同じ引き戻しを比較する。

K の元 x について H′_x の fibre との交点は `Σ_{i≠k}[εᵢₖ]₊xᵢ` である。従って Iₖ(H′_x−ΣxᵢE′ᵢ) の Eₖ との交点は `−xₖ+Σ_{i≠k}[εᵢₖ]₊xᵢ`、他の Eᵢ との交点は xᵢ となる。これが Bₖx であり、補助模型上で Iₖ∘ι̃_P′=ι̃_P∘Bₖ を得る。節点縮約を降りた写像では ι̃ を ι に置き換える。

基本変換のトーラス公式と中心写像は

    Ψₖ,c* z′ʰ=zʰ(1+cₖzᵛᵏ)^(−det(h,vₖ)),
    c′ₖ=cₖ⁻¹,  c′ᵢ=cᵢcₖ^[εᵢₖ]₊ (i≠k)

である。新しい電荷を代入すると X 変異となり、標識と Picard 引き戻し、中心と評価の二つの可換式を同時に得る。toric linear map はラベル同定、torus translation は中心の枠変更、節点細分は X 関数を変えない操作である。これらについても可換式を保つことを確かめる。

与えられた同型 ψ:Y₀→Y₁ の Picard 作用を実現するには、終域の toric contraction を ψ で始域へ引き戻してから上の定理を適用する。単に「二つの模型を何らかの語で結べる」としては、指定した ψ の作用を再現したことにならない。

### F. 向きを保つ群の全単射

#### 同じ X 写像から同じ格子作用へ

同じ表示 P₀,P₁ に対する二つの幾何的実現 ψ_a:Y_P₀(c)→Y_P₁(c_a) が同じ X 写像を持ち、終域の rank H₁=2 とする。x∈K₁ に対し Xˣ は終域曲面で定数 c_aˣ なので、c₁|_K₁=c₂|_K₁ である。中心をトーラス平行移動 τ:Y_P₁(c₂)→Y_P₁(c₁) で整列する。この平行移動は標識と向きに関して恒等である。

残差 α=τψ₂ψ₁⁻¹ は H₁ の全指標を固定する。sN₁⊂H₁ なので N₁ の各基底 e に対して

    r_e=(α*zᵉ)/zᵉ,  r_eˢ=1.

ℂ は代数閉なので r_e は定数の 1 の冪根であり、α はトーラス上である j∈J₁ の平行移動に一致する。j は全内部中心を固定して曲面へ延びる。稠密開上の等号から α=j となり、二つの Picard 作用、境界対応、向きは一致する。

#### 同じ格子作用から同じ X 写像へ

一般の対では、向きを保ち、各境界成分を固定する Picard 自明自己同型を取る。節点と枝を固定するため選んだ節点 blowup へ持ち上がり、内部例外曲線の類を固定する。負の自己交点の既約曲線はその有効類の唯一の代表なので、相異なる中心の内部例外曲線を固定する。内部 blowdown を降りるとトーリック境界成分を各々保つ自己同型となる。

トーラスの自己同型は Laurent 環の単元を単元へ送るため、単項式の線形部分と定数平行移動に分かれる。線形部分は全原始境界射線を固定するので恒等、中心の保存は平行移動が H 上自明であることを意味する。従って自己同型は J の元である。これは [GHK-M] Proposition 2.6 の必要部分の直接証明で、J の有限性は用いない。

同じ P₀,P₁ の二つの実現の I、β、η が一致するとする。中心写像の支配性により両終端を相異なる中心の開集合に同時に入れる。周期の自然性 a₁(x)=a₀(Ix)^η と同じ表示の中心比の公式から、両終端の K 指標が一致する。整列後の差は向きと各境界成分を保つ Picard 自明自己同型なので J に属し、全 Xᵢ を固定する。ev_P₀ は中心の任意の非空開集合に制限しても支配的なので、独立変数上で F₁=F₂ を得る。

対象対では境界類の一次独立性から I が β を決める。反転なしの語では η=1 なので I の一致だけで比較できる。符号付きの一般比較では η を保持する。

#### 全射性

g∈G⁺ に対し、D 節で根を避ける a₀ と a₁=a₀∘g|_K を固定表示の中心として実現する。D 節の再構成から、引き戻し g の対の同型を得る。E 節の指定された同型の因数分解を適用する。各段を X 変異、ラベル同定、X を変えない枠変更へ読み替えるとループが得られ、その Picard 作用は g である。これで Γᵒᵖ→G⁺ は全単射となる。

### G. 符号付き拡大

向きだけを逆にした表示では det̄=−det、z̄ʰ=(zʰ)⁻¹ である。中心方程式 1+cᵢzᵛⁱ=0 は 1+cᵢ⁻¹z̄ᵛⁱ=0 と同じなので、c̄=c⁻¹、X̄=X⁻¹ となる。これは同じ曲面の恒等写像を異なる表示の間で読む操作である。

この恒等の underlying map の Picard 作用は id であり、境界の向きだけが反転する。根を避ける a₀ を固定し、a₁(x)=a₀(g₀x)⁻¹ を同じ表示 P の中心として実現する。4.4 の向き −1 の系は、g₀ を引き戻しとし、D₀ の順像が D₂ⱼ₀ である同型を与える。先に P→P̄ の表示反転を適用すれば、残りは P̄→P の向きを保つ指定された同型となる。

D 節の再構成と E 節の因数分解により −ε から ε への反転なしの語 p₀ を得る。最初に ς を実行した語 o は奇のループで、Picard 作用は g₀ である。標識を μg₀ に変更して読む場合も、生の表示反転の作用 id に g₀ を重ねて二度適用しない。

反転と変異・置換の交換関係から、任意の奇の語は o と偶の語の合成として書ける。従って全ての符号付きループが一般の中心で曲面同型として実現する。同じ X 写像の二つの実現は F 節の議論により同じ向きを持つので、偶奇が群へ降下する。

Θ(F)=(g_F,η_F) と定める。引き戻しにより Θ(F∘F′)=Θ(F′)Θ(F)。核は η=1 の部分にあり、F 節の単射性から自明である。像は G⁺ と (g₀,−1) を含み、A 節の半直積から Ĝ 全体となる。

変異とラベル変更では単項式の指数作用が Picard 引き戻しに一致する。反転では幾何的引き戻しは id、単項式作用は −id である。合成して w_F=η_Fg_F|_K を得る。特に g_Fδ=δ と w_Fδ=η_Fδ が同時に成り立つ。

η と D₀ の順像 j が分かれば g_F の全境界像は `D_l↦D_{η(l−j)}` である。A 節の忠実性より、(η,w_F,j) の一致から g_F の一致が従う。Θ の単射性が関係式の十分性を与え、逆方向は同じ有理写像の単項式・付値・偶奇の一致である。

### H. 四頂点の生成元の完全性

ℙ¹×ℙ¹ の二つのファイバー類を H₁,H₂、四節点の全例外類を E₁,…,E₄、その四つの境界例外曲線の内部 blowup の全例外類を F₁,…,F₄ とする。Gram 行列は H₁²=H₂²=0、H₁H₂=1、Eᵢ²=Fᵢ²=−1、他の積は零である。

    D₀=H₁−E₁−E₄,  D₁=E₁−F₁,
    D₂=H₂−E₁−E₂,  D₃=E₂−F₂,
    D₄=H₁−E₂−E₃,  D₅=E₃−F₃,
    D₆=H₂−E₃−E₄,  D₇=E₄−F₄.

全成分の平方は −2、隣接積は 1、その他は零である。δ=2H₁+2H₂−ΣEᵢ−ΣFᵢ は原始的で平方零であり、各境界成分との交点が零、その他の既約曲線との交点が非負なので nef である。

    κ₁=H₁+H₂−E₁−E₃−F₁−F₃,
    κ₂=H₁+H₂−E₂−E₄−F₂−F₄

が K の基底になる。境界との直交式を順に解くと、Eᵢ と Fᵢ の係数が等しく、対角の二組ごとに一致し、H₁,H₂ の係数がその二値の和になる。従って他の整数生成元は不要である。K の Gram 行列は [[−2,2],[2,−2]]、δ=κ₁+κ₂。内部例外類との交点は κ₁↦e₁+e₃、κ₂↦e₂+e₄ となる。

K を固定し Dᵢ を Dᵢ₊ₖ に移す等長変換を考える。x=E₁−E₂ について

    4x=−D₀+2D₁+D₂+3D₄+2D₅+D₆−2κ₁.

従って g(x) は右辺の D の添字を k だけずらして求まる。基底順を (H₁,H₂,E₁,E₂,E₃,E₄,F₁,F₂,F₃,F₄) とすると、k=1,2,3 の像はそれぞれ次の通りである。

    k=1: (−1/2, 1/2, −1/4, −1/4, 3/4, −1/4, 3/4, −1/4, −1/4, −1/4),
    k=2: (0, 0, 1/2, 1/2, −1/2, −1/2, 1/2, −1/2, 1/2, −1/2),
    k=3: (1/2, −1/2, 1/4, −3/4, 1/4, 1/4, 1/4, 1/4, 1/4, −3/4).

いずれも非整なので L の自己同型にはならない。H₁,H₂ を固定し Eᵢ,Fᵢ を Eᵢ₊₂,Fᵢ₊₂ に移す半回転 r は整数等長変換であり、K を固定して Dⱼ↦Dⱼ₊₄ とする。r との合成で k=5,6,7 も除外される。k=0 と 4 の一意性は A 節によるため、K 作用の核は {id,r} である。

基底 (κ₁,δ) では、δ を固定する K の整数等長変換は κ₁↦±κ₁+lδ の形である。π₂ は κ₁↦−κ₁+δ、T は κ₁↦κ₁+δ を誘導するので、両者の像は可能な全群を生成する。また π₂² は非恒等な半回転 r に対応する。従って任意の Γ の元は π₂,T の語と同じ K 作用を持ち、その差も π₂² の冪として表される。これで Γ=⟨π₂,T⟩、奇の π₁ を加えて Γ̃=⟨π₁,π₂,T⟩ が得られる。

[BGM] (3.1) の語と比較するときは X=y⁻¹ による共役を取る。群全体を生成することは上の核と像の計算によるものであり、同論文の部分群包含から推論していない。

### 数学的な境界

最終的に決定する群は、原始的 nef 平方零の反標準節点サイクルのトーリック表示から得られる、有限ラベル格子上の X 有理写像群である。補助理論の範囲は各項で指定し、その対象をこの最終条件に限定しない。量子化、散乱図、全モジュライスタック、楕円曲線の解析的一意化、全ての型の Weyl 群像・Cremona 群の一覧、任意の指定した特殊周期での自己同型群の分類は含めない。任意の二つの特殊な端点の間で語が存在するための全 chamber 条件も含めない。

[FG] §1.2.5 は A と X の双方で自明な語による商を定義している。本書の商との一致は仮定せず、変異公式だけを共用する。[Mizuno] の自由被覆は周囲の群が有限生成とは限らないため、その指標スキーム上の群と本書の T(A) 上の群も同一視しない。[BGM] Theorem 3.1 と [Mizuno] Theorem 3.35 の部分群・単射の構成を、群全体の決定の代わりには使わない。

### 再利用する基本定理の受入仕様

個々の成果は、主定理から独立して利用できる次の出口を持つ。これらは補足的な一般化ではなく、それぞれの担当項目の一部である。

| 対象 | 基本 API と比較定理 | 担当 |
| --- | --- | --- |
| 指標トーラスと語 | 格子写像の反変性、恒等・合成・基底変更、有理写像の等号、語の逆と商 | 0.1–0.4 |
| 境界付き整数格子 | 飽和、双対の延長、直交分解、反転対合、制限作用の忠実性 | 1.1–1.4 |
| 曲面の線束と blowup | 既存 Cartier–Picard 比較、特異曲線次数、引き戻し、交点、全例外類、cohomology 比較 | 2.0–2.3 |
| 表示と周期 | 標準標識、境界直交類と K の同型、中心整列、周期の比・自然性、節点操作との互換 | 3.1–3.4 |
| 幾何的表示変更 | 指定射の正規化、一変異の全 Picard 同型、評価の可換式、語の合成と境界付値 | 5.1–5.5 |
| 幾何的実現 | 制限・恒等・合成、中心写像が双有理な場合の逆、同じ X 写像と同じ作用の比較 | 6.0 |

境界を持たない点 blowup、内部中心が零のトーリック対、平方零でない Looijenga 対にも、対応する一般の定義と定理を適用できる。有限指数・根の不存在・豊富錐対応などの仮定は、必要な結論の箇所で保持する。

### Lean の受入仕様

[Suggested.lean](Suggested.lean) は 1.2 の格子の主要定理を、実体のある有限自由加群と双線形形式の上に述べる。単模性は形式から双対への写像の全単射性、原始性は δ を 1 に移す整数線形形式の存在で表す。定義が結論を含む構造や、未指定の Prop を導入しない。

群同定と関係式判定を述べるには、0.2–0.3 の X 有理写像群、3.1 の標識付き表示、6.1 の幾何的引き戻しを先に構成する必要がある。これらは本書の構成目標であり、空の代替型による theorem は置かない。各項の「証明する」は、指定した命題と証明経路を Lean の定理として実装する義務を意味する。数学的結論を未指定の仮定として受け取ることや、形式化中に命題そのものを決め直すことを意味しない。格子定理の Lean 署名の型検査、数学的仕様と証明経路の確定、全定理の Lean 証明完了はそれぞれ別の受入条件である。

## Exact supplier contracts

### From Mathlib

有限自由整数加群には `Module.Free`、`Module.Finite`、基底、`LinearMap`、`LinearEquiv` を用いる。指標の整数格子は加法群であり、群環は `AddMonoidAlgebra`、関数体は `FractionRing`、関数体同型は `AlgEquiv` とする。群の反対群によって点写像と引き戻しの合成順を対応させる。有限核の基底・Smith 標準形・原始元の基底延長のうち証明が必要な特殊命題は 1.1、3.2–3.3 の目標に含める。

格子の形式には `LinearMap.BilinForm`、対称性には `LinearMap.BilinForm.IsSymm`、等長同型には `LinearMap.BilinForm.IsometryEquiv` を用いる。署名の出典は Mathlib の `LinearAlgebra/BilinearForm/Basic.lean`、`Properties.lean`、`IsometryEquiv.lean` である。曲面は `AlgebraicGeometry.Scheme` とその ℂ 上の構造射を用いて扱う。

### From Tau Ceti: 整数格子

`TauCeti.IntegralLattice` と `TauCeti.IntegralLattice.integralForm` は整数格子とその整数値形式を与える（`TauCeti/LinearAlgebra/IntegralLattice/Basic.lean`）。非退化性は独立の条件なので、退化した K に非退化性を誤って要求しない。抽象的な Picard 加群を使う 1.2 の署名は、同じ整数双線形形式の言葉で直接述べる。

`LinearMap.BilinForm.isCompl_orthogonal_of_restrict_bijective`（`TauCeti/LinearAlgebra/BilinearForm/Orthogonal.lean`）の、部分加群上の制限形式が完全な場合の直交補との分解を 1.2 で利用する。原始部分加群に関する残りの整数計算は 1.1 の目標である。

### From Tau Ceti: 射影スキームとコホモロジー

2.0 の層は `F:X.Modules` に対する `SheafOfModules.IsQuasicoherent` と `SheafOfModules.IsFiniteType` で扱い、局所 Noetherian 上で coherent 条件と同定する。射影性は `AlgebraicGeometry.Scheme.IsProjectiveOver`（`ProjectiveSpectrum/ProjectiveOver.lean`）、層コホモロジーは `TauCeti.AlgebraicGeometry.Scheme.Modules.Cohomology`（`Cohomology/Basic.lean`）、整数 twist は `AlgebraicGeometry.Proj.twistingSheaf`（`ProjectiveSpectrum/TwistingSheaf/Basic.lean`）を用いる。有限性はこの cohomology の ℂ 加群の有限次元性、消滅はその型の `Subsingleton` として述べる。

`AlgebraicGeometry.Scheme.Modules.subsingleton_cohomology_succ_of_isAffine`（`Cohomology/Affine.lean`）と `AlgebraicGeometry.Scheme.Modules.homologyCechComplexLinearEquiv`（`Cohomology/Cech/Linear.lean`）を、quasi-coherent sheaf のアフィン消滅と、有限アフィン被覆の基底環線形な Čech 比較に使う。被覆の有限交叉のアフィン性は separated なスキーム上で供給する。

`AlgebraicGeometry.Scheme.Modules.isFinitePresentation_pushforward_of_isFinite`（`Modules/Quasicoherent/Pushforward/Finite.lean`）を、局所 Noetherian な標的への有限射の coherent pushforward に使う。`AlgebraicGeometry.Scheme.Hom.cohomologyPushforwardBaseLinearEquiv`（`Cohomology/ClosedImmersion/Linear.lean`）は基底上の閉埋込みに対する全次数の比較を与える。一般の有限射の全次数比較・射影公式、必要な Serre vanishing と支持次元の消滅は 2.0 で供給する。

射影空間では `TauCeti.SymmetricAlgebra.cohomologyZeroTwistingSheafLinearEquiv`（`Cohomology/ProjectiveSpace/TwistingSheaf.lean`）の非負 twist の H⁰ 計算と、`Module.Basis.subsingleton_cohomology_twistingSheaf_of_lt_card`（`Cohomology/ProjectiveSpace/HigherCohomology.lean`）の中間消滅を利用する。`TauCeti.AlgebraicGeometry.projectiveLine.finite_cohomology`（`Cohomology/ProjectiveLine/Basic.lean`）と、同 namespace の `finrank_cohomology_zero_twistingSheaf`、`finrank_cohomology_one_twistingSheaf`（前記 `TwistingSheaf.lean` と `Cohomology/ProjectiveLine/NegativeTwist.lean`）が ℙ¹ の有限性と O(d) の計算を供給する。ℙ² の必要な上次数計算と trace・pairing は 2.0・2.3 の目標に含める。

### From Tau Ceti: 曲面と線束

`TauCeti.AlgebraicGeometry.LineBundleClass` は可逆層の同型類を与える（`TauCeti/AlgebraicGeometry/LineBundle/Class.lean`）。Picard 群の加法記法はその `Additive` を用いる。同 namespace の `LineBundleClass.pullback` と `LineBundleClass.pullbackHom`（`LineBundle/Functoriality.lean`）は射 f:X→Y に対し Y の線束を X へ引き戻す。

Cartier 因子との辞書には既存 `TauCeti.AlgebraicGeometry.Scheme.CartierDivisor.toLineBundleClassHom`（`CartierDivisor/Picard.lean`）と `TauCeti.AlgebraicGeometry.Scheme.CartierDivisor.classGroupAddEquivLineBundleClass`（`CartierDivisor/ClassGroup.lean`）を使う。後者は整スキーム X について Cartier 類群と `Additive (LineBundleClass X)` の同型を与える。2.1 はこの辞書を利用し、有効類、標準束、曲面交点に接続する。

`TauCeti.AlgebraicGeometry.LineBundleClass.intersectionNumber`（`IntersectionNumber/Basic.lean`）は指定した曲線への線束制限の Euler 次数を与える。既存の加法性 `LineBundleClass.intersectionNumberHom` は、整・proper・相対次元 ≤1、余次元 1 の局所環が DVR、H¹(O_C) の有限次元性などを仮定する。2.0 が有限性を供給し、2.1 の有限正規化の比較が特異曲線を含む次数へ接続する。この宣言を曲面の Picard 群上の交点形式そのものとはしない。

`AlgebraicGeometry.Scheme.Modules.eulerCharBelow` と `eulerCharBelow_congr`、`eulerCharBelow_eq_add`（`TauCeti/AlgebraicGeometry/Cohomology/EulerCharacteristic.lean`）を Euler 標数とその同型不変性・加法性に使う。`finrank` による有限和の定義だけから有限次元性は得られない。2.0 で有限性と高次消滅を証明し、曲面では切断次数 3 の加法性に必要な H³ の消滅を供給する。

`AlgebraicGeometry.Scheme.IdealSheafData.blowup`、`blowupToBase`、`blowupLift`（`TauCeti/AlgebraicGeometry/Blowup/IdealSheaf.lean` と `UniversalProperty.lean`）を閉点 ideal の blowup とその普遍性に用いる。曲面での Picard・標準類の式、滑らかさ、コホモロジー比較、縮約、共通解消は 2.2–2.4 の対象である。

### From Tau Ceti: 代数的トーリック曲面

`TauCeti.Toric.Fan` と `TauCeti.Toric.Fan.algebraicRealization`（`TauCeti/Geometry/Toric/Algebraic/Fan/Basic.lean` と `Scheme.lean`）から有限扇のスキームを得る。Fan の型そのものは滑らかさ・完備性を含まないため、それらを 2.5 の入力に明記する。単項式の付値、境界交点、共通細分と模型変更の必要な特殊形は 2.5 と Layer 5 で証明する。
